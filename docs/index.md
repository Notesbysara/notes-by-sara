# The finance learning path

Notes by Sara covers finance in **nine subjects**, arranged so each one builds on the one before it. Start with Foundations if you are new to finance, or jump to the subject you are studying now.

New notes are published subject by subject. **Foundations is open now**, beginning with [Time Value of Money](/notes/foundations/time-value-of-money).

## How each note works

Every note follows the same structure, so you always know where to look:

1. **The idea in plain words**, before any formula.
2. **The formula**, with every term explained.
3. **A worked example**, with each step shown.
4. **Common mistakes** students make in exams.
