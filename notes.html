The finance learning path

Notes by Sara covers finance in 19 stages and more than 470 topics, arranged so each stage builds on the one before it. Start at Stage 1 if you are new to finance, or jump to the stage you are studying now.

New notes are published stage by stage. Stage 1 is open now, beginning with Time Value of Money.

How each note works​

Every note follows the same structure, so you always know where to look:

  1. The idea in plain words, before any formula.
  2. The formula, with every term explained.
  3. A worked example, with each step shown.
  4. Common mistakes students make in exams.
