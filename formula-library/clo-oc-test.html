CLO Overcollateralization Test

IntermediateFixed IncomeAlso known as: collateralized loan obligation, coverage test, OC trigger, cash flow diversion
← Climate Disclosure: Carbon Intensity and Financed EmissionsCoefficient of Variation →

Finds: whether each CLO class is within its coverage test.

When to use it: Use it to check the cushion each CLO note class has. Each class is tested against its own trigger. If the ratio falls below the trigger, interest that would go to junior holders is used to repay senior notes instead, which protects the senior investors.

FormulaExampleCalculator

The formula

OCk\displaystyle OC_{k}=Collateral par∑j≤kNotesj\displaystyle =\frac{\text{Collateral par}}{\sum_{j\le k}\text{Notes}_{j}}

In words: OC ratio for class k = Collateral par value / (Total of the notes in class k and every class senior to it)

What each symbol means

Collateral parPar value of the loans in the pool, with defaulted loans at their market valuemoney
Notes_jBalance of note class j, from the most senior downmoney
TriggerMinimum OC ratio. If a class fails, cash is diverted to repay senior notespercent

Worked example

A CLO has loans with a par value of 500 and note classes of A 300, B 60 and C 40. The OC triggers are 150%, 130% and 120%. What are the ratios, and how much can collateral fall before class C fails?

Cumulative notes through each class300, 360, 400
OC ratio for each class166.67%, 138.89%, 125%
Collateral that could be lost before the last class fails500−[1.5, 1.3, 1.2][−1] × [300, 360, 400][−1]20
The answer

The OC ratios for classes A, B and C are 166.67%, 138.89%, 125%. All pass their triggers of 150%, 130% and 120%. The tightest margin is class C, which would fail if collateral par dropped by 20.
