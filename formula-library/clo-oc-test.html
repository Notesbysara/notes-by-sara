CLO Overcollateralization Test

Intermediate

Also known as: collateralized loan obligation, coverage test, OC trigger, cash flow diversion

Whether each CLO class is within its coverage test. Use it to check the cushion each CLO note class has. Each class is tested against its own trigger. If the ratio falls below the trigger, interest that would go to junior holders is used to repay senior notes instead, which protects the senior investors.

The formula

OCk=Collateral par∑j≤kNotesjOC_{k}=\frac{\text{Collateral par}}{\sum_{j\le k}\text{Notes}_{j}}

OC ratio for class k = Collateral par value / (Total of the notes in class k and every class senior to it)

What each symbol means

SymbolMeaningUnit
Collateral parPar value of the loans in the pool, with defaulted loans at their market valuemoney
Notes_jBalance of note class j, from the most senior downmoney
TriggerMinimum OC ratio. If a class fails, cash is diverted to repay senior notespercent

Worked example

A CLO has loans with a par value of 500 and note classes of A 300, B 60 and C 40. The OC triggers are 150%, 130% and 120%. What are the ratios, and how much can collateral fall before class C fails?

  1. Cumulative notes through each class= 300.00, 360.00, 400.00
  2. OC ratio for each class = collateral / cumulative notes= 166.67%, 138.89%, 125.00%
  3. Collateral that could be lost before the last class fails = collateral - trigger x cumulative notes500-[1.5, 1.3, 1.2][-1] x [300, 360, 400][-1]= 20.00

The OC ratios for classes A, B and C are 166.67%, 138.89%, 125.00%. All pass their triggers of 150%, 130% and 120%. The tightest margin is class C, which would fail if collateral par dropped by 20.00.
