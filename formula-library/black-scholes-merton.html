Black-Scholes-Merton Option Price

Intermediate

Also known as: Black Scholes, BSM, European option pricing, d1 and d2

The fair price of a European call and put. Use it to price European options on a share, index or currency when volatility is steady. It assumes continuous trading, constant volatility and interest rates, and no jumps, so it is a benchmark and not a perfect model. It does not handle early exercise of American options.

The formula

C=Se−qTN(d1)−Ke−rTN(d2), P=Ke−rTN(−d2)−Se−qTN(−d1), d1=ln⁡(S/K)+(r−q+σ2/2)TσT, d2=d1−σTC=S e^{-qT}N(d_{1})-K e^{-rT}N(d_{2}),\ P=K e^{-rT}N(-d_{2})-S e^{-qT}N(-d_{1}),\ d_{1}=\frac{\ln(S/K)+(r-q+\sigma^{2}/2)T}{\sigma\sqrt{T}},\ d_{2}=d_{1}-\sigma\sqrt{T}

Call = S x e^(-qT) x N(d1) - K x e^(-rT) x N(d2); Put = K x e^(-rT) x N(-d2) - S x e^(-qT) x N(-d1); d1 = [ln(S/K) + (r - q + sigma^2 / 2) x T] / (sigma x sqrt(T)); d2 = d1 - sigma x sqrt(T)

Worked example

A stock is at 100 and pays no dividend. The strike is 100, the risk-free rate is 5%, volatility is 20% and expiry is 1 year. What are the call and put prices?

  1. d1 = [ln(S/K) + (r - q + sigma^2 / 2) x T] / (sigma x sqrt(T))(ln(100 / 100)+(0.05-0+0.2^2 / 2) x 1) / (0.2 x sqrt(1))= 0.3500
  2. d2 = d1 - sigma x sqrt(T)d1-0.2 x sqrt(1)= 0.1500
  3. Call = S e^(-qT) N(d1) - K e^(-rT) N(d2)= 10.45
  4. Put = K e^(-rT) N(-d2) - S e^(-qT) N(-d1)= 5.57
  5. Call - put10.4506-5.57353= 4.88

With d1 = 0.3500 and d2 = 0.1500, the call is worth 10.45 and the put 5.57. Put-call parity checks out: call minus put is 4.88, equal to the stock minus the present value of the strike.
