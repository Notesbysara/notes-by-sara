Arbitrage Pricing Theory (APT) Expected Return

Intermediate

Also known as: APT, multi factor model, factor betas, arbitrage pricing

Return implied by several risk factors. Use it when several economic factors drive returns, not just the market. The CAPM is the special case with one factor, the market.

The formula

E(R)=rf+∑kβk λkE(R)=r_{f}+\sum_{k}\beta_{k}\,\lambda_{k}

Expected return = rf + beta1 x premium1 + beta2 x premium2 + ...

What each symbol means

SymbolMeaningUnit
E(R)Expected return of the assetper year
r_fRisk-free rateper year
beta_kSensitivity of the asset to risk factor k (such as inflation or GDP growth)number
lambda_kRisk premium earned for one unit of exposure to factor kper year

Worked example

The risk-free rate is 3%. A stock has betas of 1.2, 0.8 and 0.5 to three factors, whose premiums are 3%, 2% and 1.5%. What return does APT predict?

  1. Beta x premium for each factor= 3.60%, 1.60%, 0.75%
  2. Total factor premium= 5.95%
  3. Expected return = rf + factor premium0.03+0.0595= 8.95%

The factors add 5.95% to the risk-free rate, so the expected return is 8.95%.
