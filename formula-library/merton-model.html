Merton Credit Model (Equity as a Call on Assets)

Intermediate

Also known as: structural credit model, distance to default, Merton default probability, KMV

Equity value, default probability and spread from the balance sheet. Use it to see credit risk as an option. Equity holders own a call option on the firm's assets with the debt as the strike. The firm defaults if its assets are below the debt when it falls due. The model turns asset value, debt and volatility into a default probability and credit spread. The default probability is risk-neutral, so it overstates the real-world probability.

The formula

E=V N(d1)−D e−rTN(d2),PD=N(−d2),s=−1Tln⁡V−ED−rE=V\,N(d_{1})-D\,e^{-rT}N(d_{2}),\quad PD=N(-d_{2}),\quad s=-\frac{1}{T}\ln\frac{V-E}{D}-r

Equity value E = V x N(d1) - D x e^(-rT) x N(d2); Default probability = N(-d2); Credit spread = -(1/T) x ln[(Firm value - Equity) / Debt] - risk-free rate; d1 = [ln(V/D) + (r + sigma^2 / 2) x T] / (sigma x sqrt(T))

What each symbol means

SymbolMeaningUnit
VMarket value of the firm's assetsmoney
DFace value of debt due at time Tmoney
sigmaVolatility of the firm's assetsper year
TTime until the debt is dueyears
rRisk-free rateper year
N()Cumulative standard normalnumber

Worked example

A firm has assets of 100, debt of 70 due in 1 year, asset volatility of 25% and a risk-free rate of 4%.

  1. d1 = [ln(V/D) + (r + sigma^2 / 2) T] / (sigma sqrt(T))(ln(100 / 70)+(0.04+0.25^2 / 2) x 1) / (0.25 x sqrt(1))= 1.7117
  2. d2 = d1 - sigma sqrt(T)d1-0.25 x sqrt(1)= 1.4617
  3. Equity = V N(d1) - D e^(-rT) N(d2)= 33.23
  4. Market value of the debt = V - E100-33.2336= 66.77
  5. Default probability = N(-d2)= 7.19%
  6. Credit spread = -ln(debt value / D) / T - r-ln(66.7664 / 70) / 1-0.04= 0.73%

Equity is worth 33.23, so debt is worth 66.77 against a face value of 70. The default probability is 7.19% and the implied credit spread is 0.73%.
