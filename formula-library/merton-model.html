Merton Credit Model (Equity as a Call on Assets)

IntermediateRisk ManagementAlso known as: structural credit model, distance to default, Merton default probability, KMV
← Merchant Cost of a Digital PaymentMinimum-Variance Hedge Ratio →

Finds: equity value, default probability and spread from the balance sheet.

When to use it: Use it to see credit risk as an option. Equity holders own a call option on the firm's assets with the debt as the strike. The firm defaults if its assets are below the debt when it falls due. The model turns asset value, debt and volatility into a default probability and credit spread. The default probability is risk-neutral, so it overstates the real-world probability.

The formula

In words: Equity value E = V x N(d1) − D x e^(-rT) x N(d2); Default probability = N(-d2); Credit spread = -(1/T) x ln[(Firm value − Equity) / Debt] − risk-free rate; d1 = [ln(V/D) + (r + sigma^2 / 2) x T] / (sigma x sqrt(T))

Worked example

A firm has assets of 100, debt of 70 due in 1 year, asset volatility of 25% and a risk-free rate of 4%.

d1(ln(100 ÷ 70) + (0.04 + 0.25^2 ÷ 2) × 1) ÷ (0.25 × sqrt(1))1.7117
d2d1 − 0.25 × sqrt(1)1.4617
Equity33.23
Market value of the debt100 − 33.233666.77
Default probability7.19%
Credit spread−ln(66.7664 ÷ 70) ÷ 1 − 0.040.73%
The answer

Equity is worth 33.23, so debt is worth 66.77 against a face value of 70. The default probability is 7.19% and the implied credit spread is 0.73%.
