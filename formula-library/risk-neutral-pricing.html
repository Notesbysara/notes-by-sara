Risk-Neutral Probability and Pricing

Intermediate

Also known as: risk neutral valuation, equivalent martingale measure, state prices, Q measure

An option price from risk-neutral probabilities. Use it to price a derivative without knowing investors' risk preferences. Pretend the world is risk-neutral, so the stock earns the risk-free rate, compute the expected payoff and discount at the risk-free rate. The real-world probability and expected return do not enter the price.

The formula

q=S0erT−SdSu−Sd,V0=e−rT[q Vu+(1−q) Vd]q=\frac{S_{0}e^{rT}-S_{d}}{S_{u}-S_{d}},\quad V_{0}=e^{-rT}\left[q\,V_{u}+(1-q)\,V_{d}\right]

Risk-neutral probability of the up state = (Spot x e^(rT) - Down price) / (Up price - Down price); Value = e^(-rT) x [q x Payoff if up + (1 - q) x Payoff if down]

What each symbol means

Worked example

A stock at 100 goes to 120 or 90 in a year, the risk-free rate is 5% and the real-world chance of an up move is 60%. Price a call with a strike of 100.

  1. q = (S0 e^(rT) - Sd) / (Su - Sd)(100 x exp(0.05 x 1)-sd) / (120-sd)= 50.42%
  2. Real-world probability0.6= 60.00%
  3. Call payoff if upmax(120-100, 0)= 20.00
  4. Call payoff if downmax(sd-100, 0)= 0.00
  5. Price = e^(-rT) x [q Vu + (1 - q) Vd]exp(-0.05 x 1) x (0.504237 x 20+(1-0.504237) x 0)= 9.59
  6. Using the real-world probability instead (wrong)exp(-0.05 x 1) x (0.6 x 20+(1-0.6) x 0)= 11.41

The risk-neutral probability of an up move is 50.42%, lower than the real-world 60.00%. The call pays 20.00 or 0.00, so it is worth 9.59. Using the real probability instead would give 11.41, which is wrong because discounting at the risk-free rate does not reflect the risk.
