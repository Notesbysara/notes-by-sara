Catastrophe Bond: Expected Loss and Risk Multiple

Intermediate

Also known as: insurance-linked securities, cat bond, expected loss, multiple at risk, ILS spread

What a catastrophe bond pays for the risk it carries. Use it to price and compare catastrophe bonds. A bond pays a high coupon, but investors lose principal if a defined event (a hurricane or earthquake) occurs. Because disaster risk is little related to the stock market, the spread is paid for risk that diversifies other holdings. The expected loss estimate comes from modeling firms, so model error is the main risk.

The formula

EL=pa×s,Multiple=SpreadEL,E[R]=rf+Spread−ELEL=p_{a}\times s,\quad \text{Multiple}=\frac{\text{Spread}}{EL},\quad E[R]=r_{f}+\text{Spread}-EL

Expected loss = probability of attachment (the event hits the bond) x average share of principal lost when it does; Multiple = spread / expected loss; Expected return = risk-free rate + spread - expected loss; Probability of losing money in a year = probability of attachment

What each symbol means

SymbolMeaningUnit
p_aChance in a year that the trigger event is large enough to hit the bondpercent
sAverage share of principal lost given the bond is hitpercent
SpreadExtra yield over the risk-free rate paid by the bondper year

Worked example

A hurricane bond has a 2.5% yearly chance of being hit. When it is hit, 60% of principal is lost on average. It pays a spread of 8% over 4% risk-free.

  1. Expected loss = p x s0.025 x 0.6= 1.50%
  2. Spread / expected loss0.08 / 0.015= 5.33
  3. Expected return = rf + spread - EL0.04+0.08-0.015= 10.50%
  4. Return in a hit year = rf + spread - s0.04+0.08-0.6= -48.0%
  5. Expected loss if the true chance is 50% higher0.025 x 1.5 x 0.6= 2.25%
  6. Expected return in that case0.04+0.08-0.0225= 9.75%

Expected loss is 1.50% a year. The spread is 5.33 times the expected loss, and the expected return is 10.50%. If the event happens the return is about -48.0%; the chance of that in any year is 2.5%. If the modellers underestimate the chance by half, the expected loss becomes 2.25% and the expected return 9.75%.
