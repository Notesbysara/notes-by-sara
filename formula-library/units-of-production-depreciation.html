Units-of-Production Depreciation

Intermediate

Also known as: usage depreciation, depreciation by output, activity method

Depreciation based on how much the asset was used. Use it when an asset wears out by use rather than by time, such as a machine rated for a number of hours or a vehicle rated for a number of kilometers.

The formula

Dep=Cost−SalvageTotal units×Units this periodDep=\frac{\text{Cost}-\text{Salvage}}{\text{Total units}}\times\text{Units this period}

Depreciation = (Cost - Salvage) / Total expected units x Units used this period

What each symbol means

SymbolMeaningUnit
CostWhat the asset costmoney
SalvageExpected value at the end of its lifemoney
Total unitsTotal output the asset is expected to produce in its lifeunits
Units this periodOutput produced this periodunits

Worked example

A machine costs 50,000, has a salvage value of 5,000 and is expected to produce 100,000 units. It produced 12,000 units this year. What is the depreciation?

  1. Depreciation per unit = (cost - salvage) / total units(50000-5000) / 100000= 0.4500
  2. Depreciation = rate x units used0.45 x 12000= 5,400.00

The depreciation for the year is 5,400.00, at 0.4500 per unit.
