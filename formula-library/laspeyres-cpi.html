Consumer Price Index (Laspeyres) and Substitution Bias

Intermediate

Also known as: CPI, inflation measurement, PCE, Paasche, Fisher ideal index

Inflation from a basket of goods and how much substitution matters. Use it to see how a price index is built and why measures differ. A fixed basket (CPI style) overstates inflation when people switch to cheaper items. An index using current quantities (Paasche) tends to understate it. PCE and chain-weighted measures update the weights to reduce this gap. Headline inflation is the change in the index over time.

The formula

CPI=∑p1q0∑p0q0×100,Paasche=∑p1q1∑p0q1×100CPI=\frac{\sum p_{1}q_{0}}{\sum p_{0}q_{0}}\times100,\quad \text{Paasche}=\frac{\sum p_{1}q_{1}}{\sum p_{0}q_{1}}\times100

Laspeyres (CPI style) = cost of the OLD basket at new prices / cost of the old basket at old prices x 100; Paasche = cost of the NEW basket at new prices / cost of the new basket at old prices x 100; Fisher = square root of (Laspeyres x Paasche)

What each symbol means

SymbolMeaningUnit
p_0, p_1Prices in the base period and the current periodmoney
q_0, q_1Quantities bought in the base period and the current periodunits
LaspeyresFixed-basket index. It ignores shifts away from items that became dearerindex

Worked example

A four-item basket has base prices 2.0, 3.5, 1.2 and 40.0 and current prices 2.2, 3.6, 1.5 and 42.0. Base quantities are 50, 20, 100, 5 and current quantities are 48, 21, 90, 6.

  1. Old basket at base prices= 490.00
  2. Old basket at current prices= 542.00
  3. Laspeyres index (base = 100)100 x 542 / 490= 110.61
  4. Inflation = index / 100 - 1110.612 / 100-1= 10.61%
  5. Paasche index= 109.80
  6. Fisher index = sqrt(Laspeyres x Paasche)sqrt(110.612 x 109.797)= 110.20
  7. Laspeyres minus Fisher, in percentage points(110.612-110.204) / 100= 0.41%

The old basket costs 490.00 at base prices and 542.00 at current prices, so the Laspeyres index is 110.61 (inflation of 10.61%). The Paasche index is 109.80 and the Fisher index 110.20, so fixed-basket CPI is 0.41% above the Fisher measure.
