Investor Sentiment Composite Index

BeginnerBehavioral FinanceAlso known as: investor sentiment, fear and greed, z-score composite, contrarian signal
← Investment Thesis: Expected Return and Margin of SafetyIPO Underpricing (Initial Return) →

Finds: one number that summarizes market mood.

When to use it: Use it to combine several sentiment gauges into one number. Standardizing puts different indicators on a common scale. Extreme readings have sometimes preceded low returns after greed and high returns after fear, which is why some investors use them as contrarian signals, though timing is poor and trends can persist for a long time. The choice of indicators and sample matters.

The formula

zi\displaystyle z_{i}=si xi−μiσi\displaystyle =s_{i}\,\frac{x_{i}-\mu_{i}}{\sigma_{i}}Sentiment\displaystyle \text{Sentiment}=1n∑zi\displaystyle =\frac{1}{n}\sum z_{i}

In words: Each indicator's z-score = sign x (current value − its average) / its standard deviation, where the sign is −1 for indicators that rise when fear rises; Composite sentiment = average of the z-scores. Above +1 reads as greed and below −1 as fear

What each symbol means

x_iCurrent value of indicator i: for example, a fund-flow measure, a put/call ratio, a volatility index, margin debtnumber
mu_i, sigma_iIts historical average and standard deviationnumber
s_iSign: +1 if the indicator rises with optimism, -1 if it rises with fearnumber

Worked example

Four indicators: current values 22, 0.62, 18, 1.4; averages 18, 0.55, 20, 1.1; standard deviations 4, 0.08, 5, 0.5; signs +1, +1, −1 (volatility index), +1.

Signed z-scores1, 0.87, 0.40, 0.60
