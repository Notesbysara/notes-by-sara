Replicating Portfolio (One-Step Binomial)

IntermediateDerivativesAlso known as: replication, synthetic option, no arbitrage option price, hedge ratio
← Rent vs Buy: Annual Cost of OwningRepo: Interest, Haircut and Repurchase Price →

Finds: A portfolio that copies an option, and its value.

When to use it: Use it to price an option by copying it. Hold delta shares and borrow or lend cash so the portfolio pays exactly what the option pays in both outcomes. The portfolio's cost today is then the option's price, with no probabilities needed.

FormulaExampleCalculator

The formula

Δ\displaystyle \Delta=Cu−CdS(u−d)\displaystyle =\frac{C_{u}-C_{d}}{S(u-d)}B\displaystyle B=Cu−ΔSu1+r\displaystyle =\frac{C_{u}-\Delta S u}{1+r}C\displaystyle C=ΔS+B\displaystyle =\Delta S+B

In words: Shares held (delta) = (Option value if up − Option value if down) / (Stock price up − Stock price down); Bond holding B = (Option value if up − Delta x Stock price up) / (1 + r); Option value = Delta x S + B

What each symbol means

C_u, C_dOption value after an up move and a down movemoney
SCurrent stock pricemoney
u, dUp and down factors for the stocknumber
BCash held, negative if borrowedmoney
rInterest rate for the periodpercent

Worked example

A stock is at 100 and will become 110 or 90 in one period. The interest rate is 5% for the period. What replicates a call with a strike of 100, and what is it worth?

Call payoff if upmax(100 × 1.1 − 100, 0)10
Call payoff if downmax(100 × 0.9 − 100, 0)0
Shares held(10 − 0) ÷ (100 × (1.1 − 0.9))0.5000
Cash holding B(10 − 0.5 × 100 × 1.1) ÷ (1 + 0.05)−42.86
Amount borrowed−−42.857142.86
Option value0.5 × 100+−42.85717.14
Risk-neutral probability(1 + 0.05 − 0.9) ÷ (1.1 − 0.9)75%
Check: [q x Cu + (1 - q) x Cd] / (1 + r)(0.75 × 10 + (1 − 0.75) × 0) ÷ (1 + 0.05)7.14
The answer

The option pays 10 if the stock rises and 0 if it falls. Holding 0.5000 shares and borrowing 42.86 copies those payoffs, so the option is worth 7.14. The risk-neutral check gives the same value.
