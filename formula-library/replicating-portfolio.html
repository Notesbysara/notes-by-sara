Replicating Portfolio (One-Step Binomial)

Intermediate

Also known as: replication, synthetic option, no arbitrage option price, hedge ratio

A portfolio that copies an option, and its value. Use it to price an option by copying it. Hold delta shares and borrow or lend cash so the portfolio pays exactly what the option pays in both outcomes. The portfolio's cost today is then the option's price, with no probabilities needed.

The formula

Δ=Cu−CdS(u−d),B=Cu−ΔSu1+r,C=ΔS+B\Delta=\frac{C_{u}-C_{d}}{S(u-d)},\quad B=\frac{C_{u}-\Delta S u}{1+r},\quad C=\Delta S+B

Shares held (delta) = (Option value if up - Option value if down) / (Stock price up - Stock price down); Bond holding B = (Option value if up - Delta x Stock price up) / (1 + r); Option value = Delta x S + B

What each symbol means

Worked example

A stock is at 100 and will become 110 or 90 in one period. The interest rate is 5% for the period. What replicates a call with a strike of 100, and what is it worth?

  1. Call payoff if upmax(100 x 1.1-100, 0)= 10.00
  2. Call payoff if downmax(100 x 0.9-100, 0)= 0.00
  3. Shares held = (Cu - Cd) / (S x (u - d))(10-0) / (100 x (1.1-0.9))= 0.5000
  4. Cash holding B = (Cu - delta x S x u) / (1 + r)(10-0.5 x 100 x 1.1) / (1+0.05)= -42.86
  5. Amount borrowed = -B--42.8571= 42.86
  6. Option value = delta x S + B0.5 x 100+-42.8571= 7.14
  7. Risk-neutral probability = (1 + r - d) / (u - d)(1+0.05-0.9) / (1.1-0.9)= 75.00%
  8. Check: [q x Cu + (1 - q) x Cd] / (1 + r)(0.75 x 10+(1-0.75) x 0) / (1+0.05)= 7.14

The option pays 10.00 if the stock rises and 0.00 if it falls. Holding 0.5000 shares and borrowing 42.86 copies those payoffs, so the option is worth 7.14. The risk-neutral check gives the same value.
