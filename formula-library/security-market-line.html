Security Market Line and Alpha

Intermediate

Also known as: SML, required return, over or undervalued, CAPM alpha check

Whether a stock offers enough return for its risk. Use it to check whether a stock looks cheap or expensive. A stock plotting above the line (positive alpha) offers more return than its beta requires, so it looks undervalued, and below the line it looks overvalued.

The formula

rreq=rf+β [E(Rm)−rf],α=E(R)−rreqr_{req}=r_{f}+\beta\,[E(R_{m})-r_{f}],\quad \alpha=E(R)-r_{req}

Required return = rf + beta x (E(Rm) - rf); alpha = forecast return - required return

What each symbol means

SymbolMeaningUnit
r_reqReturn the stock should offer for its betaper year
betaStock's sensitivity to the marketnumber
E(R_m)Expected market returnper year
r_fRisk-free rateper year
alphaGap between your forecast return and the required returnper year

Worked example

The risk-free rate is 3% and the market is expected to return 8%. A stock has a beta of 1.2 and you forecast a return of 10%. Is it undervalued?

  1. Required return = rf + beta x (rm - rf)0.03+1.2 x (0.08-0.03)= 9.00%
  2. Alpha = forecast - required0.1-0.09= 1.00%

The required return is 9.00%. Your forecast is higher, so alpha is 1.00% and the stock looks undervalued.
