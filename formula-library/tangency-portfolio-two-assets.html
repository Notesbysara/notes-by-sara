Optimal Risky Portfolio (Maximum Sharpe, Two Assets)

Intermediate

Also known as: optimization methods, tangency portfolio, maximum Sharpe ratio, mean variance optimization, Lagrange

The risky mix with the best return per unit of risk. Use it to find the mix of two risky assets with the highest Sharpe ratio. It comes from an optimization: maximize the Sharpe ratio subject to weights adding to 1, and set the derivative to zero. For more than two assets the same solution is found with matrix algebra or numerical optimizers.

The formula

w1∗=(μ1−rf)σ22−(μ2−rf)ρσ1σ2(μ1−rf)σ22+(μ2−rf)σ12−(μ1−rf+μ2−rf)ρσ1σ2w_{1}^{*}=\frac{(\mu_{1}-r_{f})\sigma_{2}^{2}-(\mu_{2}-r_{f})\rho\sigma_{1}\sigma_{2}}{(\mu_{1}-r_{f})\sigma_{2}^{2}+(\mu_{2}-r_{f})\sigma_{1}^{2}-(\mu_{1}-r_{f}+\mu_{2}-r_{f})\rho\sigma_{1}\sigma_{2}}

Weight in asset 1 = [(m1 - rf) x s2^2 - (m2 - rf) x rho x s1 x s2] / [(m1 - rf) x s2^2 + (m2 - rf) x s1^2 - (m1 - rf + m2 - rf) x rho x s1 x s2]; weight in asset 2 = 1 - weight in asset 1

Worked example

Asset 1 has an expected return of 10% and volatility of 20%. Asset 2 has 6% and 12%. The correlation is 0.3 and the risk-free rate is 3%.

  1. Numerator(0.1-0.03) x 0.12^2-(0.06-0.03) x 0.3 x 0.2 x 0.12= 0.000792
  2. Denominator(0.1-0.03) x 0.12^2+(0.06-0.03) x 0.2^2-(0.1-0.03+0.06-0.03) x 0.3 x 0.2 x 0.12= 0.001488
  3. Weight in asset 1 = numerator / denominator0.000792 / 0.001488= 53.23%
  4. Weight in asset 2 = 1 - w11-0.532258= 46.77%
  5. Portfolio expected return0.532258 x 0.1+0.467742 x 0.06= 8.13%
  6. Portfolio volatilitysqrt(0.532258^2 x 0.2^2+0.467742^2 x 0.12^2+2 x 0.532258 x 0.467742 x 0.3 x 0.2 x 0.12)= 13.44%
  7. Sharpe ratio = (return - rf) / volatility(0.0812903-0.03) / 0.134415= 0.382

The best mix is 53.23% in asset 1 and 46.77% in asset 2. It has an expected return of 8.13% and a volatility of 13.44%, giving the highest possible Sharpe ratio of 0.382.
