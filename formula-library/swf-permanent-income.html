Sovereign Wealth Fund Permanent Income

IntermediateBanking & Financial InstitutionsAlso known as: sovereign wealth funds, resource revenue saving, Norway 3% rule, intergenerational equity
← Sovereign Debt Restructuring: NPV HaircutSRISK (Systemic Risk Contribution) →

Finds: how much of a resource windfall can be spent each year.

When to use it: Use it to decide how much of a finite resource windfall can be spent without making future generations worse off. Treat the resource as part of wealth and spend only its return, saving the rest in a fund. This is the idea behind spending rules that cap withdrawals at an expected real return of the fund. It depends on assumptions about the price path and the real return.

FormulaExampleCalculator

The formula

W\displaystyle W=R 1−(1+r)−Nr+F\displaystyle =R\,\frac{1-(1+r)^{-N}}{r}+FPermanent income\displaystyle \text{Permanent income}=r W\displaystyle =r\,W

In words: Total wealth = present value of the remaining resource revenue (R each year for N years) + current fund; Sustainable spending (permanent income) = real return x total wealth; Amount to save each year = resource revenue − (permanent income − return on the fund)

Worked example

A state earns 30 a year from a resource that will last 25 years. It already has a fund of 100. The expected real return is 4%.

Present value of the resource revenue30 × (1 − (1 + 0.04)^(−25)) ÷ 0.04468.66
Total wealth468.662 + 100568.66
Permanent income0.04 × 568.66222.75
Return on the existing fund0.04 × 1004
Spending supported by the resource22.7465 − 418.75
Revenue to save each year30 − 18.746511.25
The answer

The resource is worth 468.66 today, so total wealth is 568.66. Permanent income is 22.75, of which 4 comes from the fund, so the resource supports 18.75 of spending now. Of the 30 of annual revenue, 11.25 should be saved each year.
