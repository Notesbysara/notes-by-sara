Sovereign Wealth Fund Permanent Income

Intermediate

Also known as: sovereign wealth funds, resource revenue saving, Norway 3% rule, intergenerational equity

How much of a resource windfall can be spent each year. Use it to decide how much of a finite resource windfall can be spent without making future generations worse off. Treat the resource as part of wealth and spend only its return, saving the rest in a fund. This is the idea behind spending rules that cap withdrawals at an expected real return of the fund. It depends on assumptions about the price path and the real return.

The formula

W=R 1−(1+r)−Nr+F,Permanent income=r WW=R\,\frac{1-(1+r)^{-N}}{r}+F,\quad \text{Permanent income}=r\,W

Total wealth = present value of the remaining resource revenue (R each year for N years) + current fund; Sustainable spending (permanent income) = real return x total wealth; Amount to save each year = resource revenue - (permanent income - return on the fund)

Worked example

A state earns 30 a year from a resource that will last 25 years. It already has a fund of 100. The expected real return is 4%.

  1. Present value of the resource revenue30 x (1-(1+0.04)^(-25)) / 0.04= 468.66
  2. Total wealth = resource PV + fund468.662+100= 568.66
  3. Permanent income = return x wealth0.04 x 568.662= 22.75
  4. Return on the existing fund0.04 x 100= 4.00
  5. Spending supported by the resource22.7465-4= 18.75
  6. Revenue to save each year30-18.7465= 11.25

The resource is worth 468.66 today, so total wealth is 568.66. Permanent income is 22.75, of which 4.00 comes from the fund, so the resource supports 18.75 of spending now. Of the 30 of annual revenue, 11.25 should be saved each year.
