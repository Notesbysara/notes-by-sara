Cybersecurity: Return on Security Investment

Intermediate

Also known as: cybersecurity and digital fraud, ROSI, risk reduction, expected annual loss

Whether a security control is worth its cost. Use it to compare security spending with the loss it prevents. Estimate the yearly expected loss before and after a control (such as multi-factor authentication or staff training). A positive return means the control pays for itself in expected terms, though rare severe events are hard to estimate and one breach can threaten a firm.

The formula

ALE=∑SLE×ARO,ROSI=(ALEbefore−ALEafter)−CostCostALE=\sum SLE\times ARO,\quad ROSI=\frac{(ALE_{before}-ALE_{after})-\text{Cost}}{\text{Cost}}

Expected yearly loss (ALE) = loss per incident x incidents per year, summed over threats; Risk reduction = ALE before - ALE after the control; Return on security investment = (risk reduction - cost of the control) / cost of the control; Break-even reduction = cost of the control / ALE before

What each symbol means

SymbolMeaningUnit
SLELoss from one incidentmoney
AROExpected incidents per yearnumber
ALEExpected loss per yearmoney

Worked example

Phishing and account takeover are expected to cost 1,200,000 a year (3 incidents of 400,000). A control costing 250,000 a year is expected to cut incidents to 0.75 a year.

  1. Expected loss before400000 x 3= 1,200,000.00
  2. Expected loss after400000 x 0.75= 300,000.00
  3. Reduction in expected loss1,200,000-300000= 900,000.00
  4. Net benefit = reduction - cost900000-250000= 650,000.00
  5. Return on security investment650000 / 250000= 260%
  6. Break-even reduction250000 / 1,200,000= 20.8%

Expected loss falls from 1,200,000.00 to 300,000.00 a year, a saving of 900,000.00. After the cost of the control the net benefit is 650,000.00, a return on security investment of 260%. The control breaks even if it removes 20.8% of the loss.
