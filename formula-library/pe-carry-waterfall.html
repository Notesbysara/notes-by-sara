Private Equity Distribution Waterfall and Carry

Intermediate

Also known as: private equity firms, carried interest, preferred return, catch-up, TVPI DPI

How a private equity fund splits its profit. Use it to see how profits split between investors (LPs) and the manager (GP) under a European (whole-fund) waterfall. Below the preferred return the manager earns no carry. The catch-up then lets the manager earn carry on all profit, not only on the excess. Multiples show performance: DPI is cash returned per unit invested, and TVPI includes unrealized value. Terms differ by fund and the example uses a single investment and exit for simplicity.

The formula

Pref=C[(1+h)T−1],Catch-up=c1−c Pref,GP=Catch-up+c (Profit−Pref−Catch-up)\text{Pref}=C\left[(1+h)^{T}-1\right],\quad \text{Catch-up}=\frac{c}{1-c}\,\text{Pref},\quad GP=\text{Catch-up}+c\,(\text{Profit}-\text{Pref}-\text{Catch-up})

Order of payment: (1) return of capital to investors, (2) preferred return, (3) catch-up to the manager until it holds the carry share of all profit, (4) remaining profit split with carry % to the manager. With full catch-up the manager ends with carry % x total profit once profits are large enough

What each symbol means

SymbolMeaningUnit
CCapital invested by the fund's investors (LPs)money
hPreferred return (hurdle), compounded each yearpercent
cCarried interest rate, often 20%percent
TYears investedyears

Worked example

Investors put in 100 and receive 220 of proceeds after 5 years. The preferred return is 8% a year, carry is 20% with a full catch-up.

  1. Profit = distributions - capital220-100= 120.00
  2. Preferred return = C x ((1 + h)^T - 1)100 x ((1+0.08)^5-1)= 46.93
  3. Full catch-up amount = carry / (1 - carry) x pref0.2 / (1-0.2) x 46.9328= 11.73
  4. Manager carrymin(max(120-46.9328, 0), 11.7332)+0.2 x max(120-46.9328-11.7332, 0)= 24.00
  5. Manager share of profit24 / 120= 20.0%
  6. Investors receive220-24= 196.00
  7. Gross multiple220 / 100= 2.20
  8. Net multiple to investors196 / 100= 1.96
  9. Net annual return to investors1.96^(1 / 5)-1= 14.41%

Profit is 120.00. The preferred return is 46.93 and the catch-up is 11.73. The manager receives 24.00, which is 20.0% of the profit, and investors receive 196.00. Net multiple to investors is 1.96 (gross 2.20) and net annual return 14.41%.
