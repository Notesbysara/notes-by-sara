Future Value of an Annuity Due

Intermediate

Also known as: savings at the start of the period, FV annuity due

Future value of deposits made at the start of each period. Use it for a savings plan where each deposit is made at the start of the period, so every deposit earns one extra period of interest.

The formula

FVdue=PMT×(1+r)n−1r×(1+r)FV_{due} = PMT \times \frac{(1+r)^{n}-1}{r} \times (1+r)

FV(due) = PMT x ((1 + r)^n - 1) / r x (1 + r)

What each symbol means

SymbolMeaningUnit
FV(due)Future value when deposits are made at the start of each periodmoney
PMTDeposit per periodmoney
rInterest rate per period, as a decimalper period
nNumber of depositsperiods

Worked example

You deposit 1,000 at the start of each year for 10 years at 6% a year. How much will you have at the end of year 10?

  1. Annuity factor = ((1 + r)^n - 1) / r((1+0.06)^10-1) / 0.06= 13.1808
  2. Ordinary annuity value = PMT x factor1000 x 13.1808= 13,180.79
  3. Annuity due value = ordinary value x (1 + r)13180.8 x (1+0.06)= 13,971.64
  4. Difference = annuity due - ordinary13971.6-13180.8= 790.85

You will have 13,971.64, which is 790.85 more than depositing at the end of each year.
