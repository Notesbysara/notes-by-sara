Future Value of an Annuity Due

IntermediateFinance FoundationsAlso known as: savings at the start of the period, FV annuity due
← Future Value of a Lump SumFuture Value of an Ordinary Annuity →

Finds: future value of deposits made at the start of each period.

When to use it: Use it for a savings plan where each deposit is made at the start of the period, so every deposit earns one extra period of interest.

FormulaExampleCalculator

The formula

FVdue\displaystyle FV_{due}=PMT×(1+r)n−1r×(1+r)\displaystyle = PMT \times \frac{(1+r)^{n}-1}{r} \times (1+r)

In words: FV(due) = PMT x ((1 + r)^n − 1) / r x (1 + r)

What each symbol means

FV(due)Future value when deposits are made at the start of each periodmoney
PMTDeposit per periodmoney
rInterest rate per period, as a decimalper period
nNumber of depositsperiods

Worked example

You deposit 1,000 at the start of each year for 10 years at 6% a year. How much will you have at the end of year 10?

Annuity factor((1 + 0.06)^10 − 1) ÷ 0.0613.1808
Ordinary annuity value1,000 × 13.180813,180.79
Annuity due value13,180.8 × (1 + 0.06)13,971.64
Difference13,971.6 − 13,180.8790.85
The answer

You will have 13,971.64, which is 790.85 more than depositing at the end of each year.
