DCF Capstone: From Cash Flows to Value per Share

IntermediatePractical Skills & CapstoneAlso known as: build a full DCF valuation, enterprise value to equity bridge, terminal value share, WACC sensitivity
← Days Sales Outstanding and Receivables TurnoverDCF Enterprise Value (Explicit Period plus Terminal Value) →

Finds: A value per share with its sensitivity to the discount rate.

When to use it: Use it as the last step after forecasting a real company's cash flows from its statements. Show the answer as a range, since the terminal value usually carries most of the value and small changes in WACC and growth move the answer a lot. Compare the implied multiple with peers as a sense check.

FormulaExampleCalculator

The formula

EV\displaystyle EV=∑t=15FCFt(1+w)t+FCF5(1+g)(w−g)(1+w)5\displaystyle =\sum_{t=1}^{5}\frac{FCF_{t}}{(1+w)^{t}}+\frac{FCF_{5}(1+g)}{(w-g)(1+w)^{5}}P\displaystyle P=EV−Net debtShares\displaystyle =\frac{EV-\text{Net debt}}{\text{Shares}}

In words: Enterprise value = present value of five forecast free cash flows + present value of terminal value; Terminal value = last cash flow x (1 + growth) / (WACC − growth); Equity value = enterprise value − net debt; Value per share = equity value / shares; Share of value in the terminal value = PV of terminal value / enterprise value

What each symbol means

FCF_tForecast free cash flow to the firm in year tmoney
wWeighted average cost of capitalpercent
gLong-run growth rate after year 5percent

Worked example

Five-year free cash flows are 210, 235, 260, 285 and 305. WACC is 9%, long-run growth is 2.5%, net debt is 640 and there are 120 shares.

PV of forecast cash flows991.35
Terminal value at the end of year 5[210, 235, 260, 285, 305][−1] × (1 + 0.025) ÷ (0.09 − 0.025)4,809.62
PV of terminal value3,125.92
Enterprise value991.353 + 3,125.924,117.27
Terminal value share of EV3,125.92 ÷ 4,117.2775.9%
Equity value4,117.27 − 6403,477.27
Value per share3,477.27 ÷ 12028.98
Value per share with WACC + 1 point24.27
Value per share with WACC - 1 point35.40
The answer

The present value of the five years is 991.35. The terminal value is 4,809.62, worth 3,125.92 today, which is 75.9% of enterprise value of 4,117.27. After net debt, equity is worth 3,477.27, or 28.98 a share. With WACC one point higher the value per share is 24.27, and one point lower 35.40.
