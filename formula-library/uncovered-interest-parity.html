Uncovered Interest Parity and Unhedged Return

Intermediate

Also known as: UIP, interest rate parity, expected depreciation, forward premium puzzle

The currency move that cancels an interest advantage. Use it as a benchmark for currency forecasts. If uncovered parity held, there would be no gain from holding a high-yield currency, because it would fall by the interest advantage. In the data, high-yield currencies have on average not fallen as much as parity says, which is why carry trades have earned a premium, with sharp losses in crises. The unhedged return shows what depends on the future spot.

The formula

E[S1]=S0 1+rd1+rf,Runhedged=(1+rf)S1S0−1E[S_{1}]=S_{0}\,\frac{1+r_{d}}{1+r_{f}},\quad R_{unhedged}=(1+r_{f})\frac{S_{1}}{S_{0}}-1

Uncovered parity: the expected future spot equals today's spot x (1 + domestic rate) / (1 + foreign rate), so the higher-rate currency is expected to weaken; Unhedged return in domestic currency = (1 + foreign rate) x (future spot / spot) - 1

Worked example

EUR/USD spot is 1.0850, the one-year USD rate is 5% and the EUR rate 3%. After a year the spot is 1.1200.

  1. Expected spot under parity1.085 x (1+0.05) / (1+0.03)= 1.1061
  2. Expected change in the euro1.10607 / 1.085-1= 1.94%
  3. Direction (1 = euro expected to rise, 0 = fall)1 if 0.0194175>0 else 0= 1
  4. Unhedged return of the euro deposit in USD(1+0.03) x 1.12 / 1.085-1= 6.32%
  5. Excess over the USD deposit0.0632258-0.05= 1.32%

Parity implies an expected spot of 1.1061, so the euro would be expected to change by 1.94% (direction flag 1: 1 = rise, 0 = fall). If the spot actually reaches 1.1200 the unhedged euro deposit returns 6.32% in dollars, against 5% on the dollar deposit, a gain of 1.32% over the domestic deposit.
