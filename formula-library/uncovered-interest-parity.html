Uncovered Interest Parity and Unhedged Return

IntermediateInternational FinanceAlso known as: UIP, interest rate parity, expected depreciation, forward premium puzzle
← Two-Sample Z-Test for a Difference in MeansUnemployment, Participation and Employment Rates →

Finds: the currency move that cancels an interest advantage.

When to use it: Use it as a benchmark for currency forecasts. If uncovered parity held, there would be no gain from holding a high-yield currency, because it would fall by the interest advantage. In the data, high-yield currencies have on average not fallen as much as parity says, which is why carry trades have earned a premium, with sharp losses in crises. The unhedged return shows what depends on the future spot.

In words: Uncovered parity: the expected future spot equals today's spot x (1 + domestic rate) / (1 + foreign rate), so the higher-rate currency is expected to weaken; Unhedged return in domestic currency = (1 + foreign rate) x (future spot / spot) − 1

Worked example

EUR/USD spot is 1.0850, the one-year USD rate is 5% and the EUR rate 3%. After a year the spot is 1.1200.

The answer

Parity implies an expected spot of 1.1061, so the euro would be expected to change by 1.94% (direction flag 1: 1 = rise, 0 = fall). If the spot actually reaches 1.1200 the unhedged euro deposit returns 6.32% in dollars, against 5% on the dollar deposit, a gain of 1.32% over the domestic deposit.
