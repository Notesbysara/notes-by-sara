Time-Weighted Return

IntermediateInvestments & Portfolio TheoryAlso known as: TWR, geometric linked return, manager return
← The Accounting EquationTokenized Asset: Value per Token and Cost of Access →

Finds: A manager's return, ignoring the timing of client cash flows.

When to use it: Use it to judge a manager, because it removes the effect of when clients added or withdrew money, which the manager does not control. GIPS standards require it.

FormulaExampleCalculator

The formula

TWR\displaystyle TWR=∏i=1n(1+Ri)−1\displaystyle =\prod_{i=1}^{n}(1+R_{i})-1

In words: Time-weighted return = (1 + R1) x (1 + R2) x ... x (1 + Rn) − 1

What each symbol means

R_iReturn in sub-period i, measured between cash flowspercent
nNumber of sub-periodsnumber
TWRReturn that ignores the size and timing of deposits and withdrawalspercent

Worked example

You start with 1,000. After year 1 it is worth 1,100 and you add 500 (a 10% return). In year 2 the 1,600 grows to 1,840 (a 15% return). What is the time-weighted return?

Growth multiple1.2650
Time-weighted return1.265 − 126.50%
Annualized1.265^(1 ÷ 2) − 112.47%
The answer

The time-weighted return over the two years is 26.50%, which is 12.47% a year.
