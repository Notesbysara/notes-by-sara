Time-Weighted Return

Intermediate

Also known as: TWR, geometric linked return, manager return

A manager's return, ignoring the timing of client cash flows. Use it to judge a manager, because it removes the effect of when clients added or withdrew money, which the manager does not control. GIPS standards require it.

The formula

TWR=∏i=1n(1+Ri)−1TWR=\prod_{i=1}^{n}(1+R_{i})-1

Time-weighted return = (1 + R1) x (1 + R2) x ... x (1 + Rn) - 1

What each symbol means

SymbolMeaningUnit
R_iReturn in sub-period i, measured between cash flowspercent
nNumber of sub-periodsnumber
TWRReturn that ignores the size and timing of deposits and withdrawalspercent

Worked example

You start with 1,000. After year 1 it is worth 1,100 and you add 500 (a 10% return). In year 2 the 1,600 grows to 1,840 (a 15% return). What is the time-weighted return?

  1. Growth multiple = product of (1 + R)= 1.2650
  2. Time-weighted return = multiple - 11.265-1= 26.50%
  3. Annualized = multiple^(1/years) - 11.265^(1 / 2)-1= 12.47%

The time-weighted return over the two years is 26.50%, which is 12.47% a year.
