Information Ratio and Tracking Error

Intermediate

Also known as: IR, tracking error, active return per unit of active risk

Reward for active risk against a benchmark. Use it to judge an active manager against a benchmark. Tracking error shows how far the portfolio strays from the benchmark, and the information ratio shows whether the extra risk was rewarded.

The formula

TE=σ(Rp−Rb),IR=Rp−Rb‾TETE=\sigma(R_{p}-R_{b}),\quad IR=\frac{\overline{R_{p}-R_{b}}}{TE}

Tracking error = standard deviation of (Portfolio return - Benchmark return); IR = average active return / tracking error

What each symbol means

SymbolMeaningUnit
R_p - R_bActive return, the portfolio return minus the benchmark return in each periodpercent
TETracking error, the standard deviation of the active returnspercent
IRInformation ratio, active return earned per unit of active risknumber

Worked example

Over six months a fund returned 2.5%, -1.0%, 3.0%, 1.5%, -2.0% and 4.0%, while its benchmark returned 2.0%, -1.5%, 2.2%, 1.8%, -1.2% and 3.1%. What are the tracking error and information ratio?

  1. Active return each period = portfolio - benchmark= 0.50%, 0.50%, 0.80%, -0.30%, -0.80%, 0.90%
  2. Average active return= 0.27%
  3. Tracking error = standard deviation of active returns= 0.67%
  4. Information ratio = average active return / tracking error0.00266667 / 0.00671317= 0.397
  5. Annualized tracking error = te x square root of m0.00671317 x sqrt(12)= 2.33%
  6. Annualized IR = IR x square root of m0.397229 x sqrt(12)= 1.376

The average active return is 0.27% a month with a tracking error of 0.67%, which is 2.33% annualized. The information ratio is 0.397 per month, or 1.376 annualized.
