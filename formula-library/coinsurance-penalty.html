Property Insurance Coinsurance Penalty

Beginner

Also known as: underinsurance, property insurance, coinsurance clause, insurance to value

How much a property claim pays when you are underinsured. Use it when a property policy has a coinsurance clause. If you carry less than the required share of the property's value, the insurer pays only the same share of every loss, even a small one. The fix is to insure to value and update the value as building costs rise. Not all policies have this clause, so check yours.

The formula

Payout=min⁡ ⁣(max⁡ ⁣(L×Kc V−D, 0), K)(K<cV)\text{Payout}=\min\!\left(\max\!\left(L\times\frac{K}{c\,V}-D,\,0\right),\,K\right)\quad(K<cV)

Required cover = coinsurance % x property value; If cover carried is below that, Payout = Loss x (cover carried / required cover) - deductible, capped at cover carried; otherwise Payout = Loss - deductible, capped at cover carried

What each symbol means

SymbolMeaningUnit
VReplacement value of the propertymoney
cCoinsurance requirement in the policy (often 80%)percent
KCover you actually carrymoney
LSize of the lossmoney
DDeductiblemoney

Worked example

A building is worth 300,000. The policy requires 80% cover. You carry 180,000. A 40,000 loss happens, with a 1,000 deductible.

  1. Required cover = coinsurance % x value0.8 x 300000= 240,000.00
  2. Cover carried180000= 180,000.00
  3. Share of the loss that is paid = min(carried / required, 1)min(180000 / 240000, 1)= 75.0%
  4. Payout = min(max(loss x share - deductible, 0), cover carried)min(max(40000 x 0.75-1000, 0), 180000)= 29,000.00
  5. You bear = loss - payout40000-29000= 11,000.00
  6. Penalty beyond the deductible40000-29000-1000= 10,000.00

The required cover is 240,000.00, but you carry 180,000.00, so only 75.0% of each loss is paid. The payout is 29,000.00 and you absorb 11,000.00, which is 10,000.00 more than the deductible alone.
