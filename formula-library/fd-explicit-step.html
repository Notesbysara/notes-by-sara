Finite Difference: Explicit Scheme Step and Stability

IntermediateQuantitative FinanceAlso known as: finite difference methods, heat equation, explicit scheme, numerical PDE, CFL condition
← Financial Independence Number and the 4% RuleFiscal Multiplier →

Finds: one explicit finite difference step and whether it is stable.

When to use it: Use it to solve a pricing equation on a grid by stepping forward in time. Each point moves toward the average of its neighbors, which is the discrete form of the second derivative. The explicit scheme is simple but requires small time steps for stability. Implicit and Crank-Nicolson schemes remove that limit.

The formula

uin+1\displaystyle u_{i}^{n+1}=uin+α(ui+1n−2uin+ui−1n)\displaystyle =u_{i}^{n}+\alpha\left(u_{i+1}^{n}-2u_{i}^{n}+u_{i-1}^{n}\right)α\displaystyle \alpha=D Δt(Δx)2≤12\displaystyle =\frac{D\,\Delta t}{(\Delta x)^{2}}\le\tfrac{1}{2}

In words: New value at a grid point = Old value + alpha x (Value on the right − 2 x Old value + Value on the left), with alpha = D x time step / (grid spacing)^2; the scheme is stable only if alpha <= 0.5

What each symbol means

uValue at a grid point (option value or temperature)number
DDiffusion coefficient. For Black-Scholes in log price it is sigma^2 / 2number
Delta t, Delta xTime step and grid spacingnumbers
alphaMesh ratio. Above 0.5 the explicit scheme blows upnumber

Worked example

In a grid, one point has a value of 10.0 with neighbors 8.0 and 13.0. The diffusion coefficient is 0.02, the time step 0.01 and the grid spacing 0.1. Find the next value and test the stability. Then try a time step of 0.05.

alpha0.02 × 0.01 ÷ 0.1^20.0200
Stable? (11 if 0.02<=0.5 else 01
New value10 + 0.02 × (13 − 2 × 10 + 8)10.0200
alpha with the larger time step0.02 × 0.05 ÷ 0.1^20.1000
The answer

The mesh ratio is 0.0200, within the stable limit of 0.5, and the new value is 10.0200. With a time step of 0.05 the ratio would be 0.1000, which is above 0.5, so the explicit scheme would be unstable.
