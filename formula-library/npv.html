Net Present Value (NPV)

IntermediateFinance FoundationsAlso known as: NPV, net present value formula, project value, discounted cash flow
← Net Operating Income and Cap-Rate ValuationNet Working Capital →

Finds: whether a project adds value.

When to use it: Use it to decide whether a project or investment is worth doing. Accept it when NPV is above zero and reject it when NPV is below zero.

FormulaExampleCalculator

The formula

NPV\displaystyle NPV=∑t=0nCFt(1+r)t\displaystyle = \sum_{t=0}^{n}\frac{CF_{t}}{(1+r)^{t}}

In words: NPV = sum of CF_t / (1 + r)^t, for t = 0 to n

What each symbol means

NPVNet present value, the value created in today's moneymoney
CF_tCash flow in period t. Money received is positive, money paid is negativemoney
rDiscount rate per period, as a decimalper period
tPeriod number, with t = 0 meaning todayperiods
nThe last periodperiods

Worked example

A project costs 1,000 today and returns 500 at the end of each of the next 3 years. With a discount rate of 10%, what is the NPV?

Discount each cash flow: CF_t / (1 + r)^t−1,000, 454.55, 413.22, 375.66
NPV243.43
The answer

The NPV is 243.43. It is above zero, so the project adds value.
