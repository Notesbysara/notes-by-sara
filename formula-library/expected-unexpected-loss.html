Expected and Unexpected Credit Loss

Intermediate

Also known as: EL, UL, PD LGD EAD, loss given default, exposure at default

Average and variable credit losses. Use it to size credit losses. Expected loss is the average, which should be covered by pricing and provisions. Unexpected loss is the standard deviation around it, which should be covered by capital. Regulators use PD, LGD and EAD as the inputs of the internal-ratings approach.

The formula

EL=PD×LGD×EAD,UL=EADPD σLGD2+LGD2 PD(1−PD)EL=PD\times LGD\times EAD,\quad UL=EAD\sqrt{PD\,\sigma_{LGD}^{2}+LGD^{2}\,PD(1-PD)}

Expected loss = PD x LGD x EAD; Unexpected loss = EAD x sqrt(PD x (LGD volatility)^2 + LGD^2 x PD x (1 - PD)); LGD = 1 - Recovery rate

What each symbol means

SymbolMeaningUnit
PDProbability of default in the periodpercent
LGDLoss given default, the share of the exposure lost if default occurspercent
EADExposure at default, the amount owed when default happensmoney
sigma_LGDStandard deviation of the loss given defaultpercent

Worked example

A loan of 10 million has a 2% default probability, a recovery rate of 55% and a standard deviation of loss given default of 25%.

  1. LGD = 1 - recovery1-0.55= 45.0%
  2. Expected loss = PD x LGD x EAD0.02 x 0.45 x 10,000,000= 90,000.00
  3. Expected loss as a share of the loan0.02 x 0.45= 0.90%
  4. Unexpected loss = EAD x sqrt(PD x sl^2 + LGD^2 x PD x (1 - PD))10,000,000 x sqrt(0.02 x 0.25^2+0.45^2 x 0.02 x (1-0.02))= 722,426.47
  5. Unexpected / expected722426 / 90000= 8.0

LGD is 45.0%. Expected loss is 90,000.00, or 0.90% of the loan. The unexpected loss is 722,426.47, about 8.0 times the expected loss, so capital must be held for a loss much bigger than the average.
