Prospect Theory Value of a Gamble

Intermediate

Also known as: loss aversion, Kahneman Tversky, probability weighting, value function

Whether a gamble feels attractive despite its expected value. Use it to see why people turn down favorable gambles and why they buy lottery tickets and insurance. Losses are felt about twice as strongly as equal gains, so a gamble with a positive expected value can have a negative prospect value. The parameters are averages from experiments with wide variation between people, so treat the result as a model of tendencies, not a prediction for one person.

The formula

v(x)={xαx≥0−λ(−x)βx<0,w(p)=pγ[pγ+(1−p)γ]1/γv(x)=\begin{cases}x^{\alpha}&x\ge0\\-\lambda(-x)^{\beta}&x<0\end{cases},\quad w(p)=\frac{p^{\gamma}}{\left[p^{\gamma}+(1-p)^{\gamma}\right]^{1/\gamma}}

Value of an outcome x: gains = x^alpha; losses = - lambda x (-x)^beta... precisely: gain value = x^alpha, loss value = - lambda x |x|^beta, with typical alpha = beta = 0.88 and loss aversion lambda = 2.25; Decision weight of a probability p = p^gamma / (p^gamma + (1 - p)^gamma)^(1/gamma), gamma about 0.61 for gains and 0.69 for losses; Prospect value of a gamble = w(p) x v(gain) + w(1 - p) x v(loss)

What each symbol means

SymbolMeaningUnit
alpha, betaCurvature: each extra unit of gain or loss matters a little lessnumber
lambdaLoss aversion: how much more a loss hurts than an equal gain pleasesnumber
gammaProbability weighting: small chances are over-weighted and large ones under-weightednumber

Worked example

A gamble pays +150 with a 50% chance or -100 with a 50% chance. Use the standard parameters.

  1. Expected value = p x gain - (1 - p) x loss0.5 x 150-(1-0.5) x 100= 25.00
  2. Felt value of the gain = g^alpha150^0.88= 82.22
  3. Felt value of the loss = -lambda x l^alpha-2.25 x 100^0.88= -129.47
  4. Decision weight of the gain probability0.5^0.61 / (0.5^0.61+(1-0.5)^0.61)^(1 / 0.61)= 42.1%
  5. Decision weight of the loss probability(1-0.5)^0.69 / ((1-0.5)^0.69+0.5^0.69)^(1 / 0.69)= 45.4%
  6. Prospect value = wg x vg + wl x vl0.420639 x 82.2168+0.453988 x -129.474= -24.20
  7. Accept? (1 = yes, 0 = no)1 if -24.196>0 else 0= 0

The expected value is 25.00, a gamble most investors would normally want. In prospect theory the gain is felt as 82.22 and the loss as -129.47. With decision weights of 42.1% and 45.4%, the prospect value is -24.20, so the gamble feels 0 (1 = acceptable, 0 = rejected).
