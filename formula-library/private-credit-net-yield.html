Private Credit: Net Yield after Losses and Fees

Intermediate

Also known as: direct lending, private credit and direct lending, all-in yield, illiquidity premium, levered private credit return

A private loan fund's return after losses, fees and leverage. Use it to compare a direct loan with public debt. Private loans are floating-rate, so the coupon moves with the base rate, and they pay a spread for illiquidity and for lending to smaller or private-equity-owned companies. Defaults and fees reduce it. Leverage adds to the return only when the net yield is above the cost of debt, and it adds loss in bad years.

The formula

y=SOFR+s+OIDn,Rnet=y−PD×LGD−f,Rlev=Rnet+DE(Rnet−c)y=SOFR+s+\frac{OID}{n},\quad R_{net}=y-PD\times LGD-f,\quad R_{lev}=R_{net}+\frac{D}{E}(R_{net}-c)

All-in yield = base rate + spread + upfront discount spread over the life; Expected credit loss = probability of default x loss given default; Net return = all-in yield - expected loss - fund fees; Return with leverage = net return + (debt / equity) x (net return - cost of debt)

What each symbol means

SymbolMeaningUnit
SOFRFloating base rate that the loan resets toper year
sCredit spread over the base rateper year
OIDOriginal issue discount: upfront fee as a share of the loanpercent
PD, LGDChance of default per year and share of the loan lost if it defaultspercent
D/EDebt to equity of the lending fundnumber

Worked example

A direct loan pays SOFR of 4.3% plus 6.5%, with a 2% original issue discount over 4 years. The annual default chance is 3%, the loss given default is 35% and fund fees are 1%. The fund borrows 1 for each 1 of equity at 6.5%.

  1. All-in yield = base + spread + discount / years0.043+0.065+0.02 / 4= 11.30%
  2. Expected loss = PD x LGD0.03 x 0.35= 1.05%
  3. Net return = yield - loss - fees0.113-0.0105-0.01= 9.25%
  4. Return on equity with leverage0.0925+1 x (0.0925-0.065)= 12.00%
  5. Net return if defaults double0.113-2 x 0.0105-0.01= 8.20%
  6. Levered return if defaults double0.082+1 x (0.082-0.065)= 9.90%

The all-in yield is 11.30%. Expected credit loss is 1.05% a year, so the net return is 9.25%. With the fund borrowing 1 for each 1 of equity, the return on equity is 12.00%. If defaults double, the unlevered net return becomes 8.20% and the levered 9.90%.
