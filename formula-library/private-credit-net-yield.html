Private Credit: Net Yield after Losses and Fees

IntermediateAlternative InvestmentsAlso known as: direct lending, private credit and direct lending, all-in yield, illiquidity premium, levered private credit return
← Principal Component Analysis: Variance Explained (Two Assets)Private Equity Distribution Waterfall and Carry →

Finds: A private loan fund's return after losses, fees and leverage.

When to use it: Use it to compare a direct loan with public debt. Private loans are floating-rate, so the coupon moves with the base rate, and they pay a spread for illiquidity and for lending to smaller or private-equity-owned companies. Defaults and fees reduce it. Leverage adds to the return only when the net yield is above the cost of debt, and it adds loss in bad years.

The formula

y\displaystyle y=SOFR+s+OIDn\displaystyle =SOFR+s+\frac{OID}{n}Rnet\displaystyle R_{net}=y−PD×LGD−f\displaystyle =y-PD\times LGD-fRlev\displaystyle R_{lev}=Rnet+DE(Rnet−c)\displaystyle =R_{net}+\frac{D}{E}(R_{net}-c)

In words: All-in yield = base rate + spread + upfront discount spread over the life; Expected credit loss = probability of default x loss given default; Net return = all-in yield − expected loss − fund fees; Return with leverage = net return + (debt / equity) x (net return − cost of debt)

What each symbol means

SOFRFloating base rate that the loan resets toper year
sCredit spread over the base rateper year
OIDOriginal issue discount: upfront fee as a share of the loanpercent
PD, LGDChance of default per year and share of the loan lost if it defaultspercent
D/EDebt to equity of the lending fundnumber

Worked example

A direct loan pays SOFR of 4.3% plus 6.5%, with a 2% original issue discount over 4 years. The annual default chance is 3%, the loss given default is 35% and fund fees are 1%. The fund borrows 1 for each 1 of equity at 6.5%.

All-in yield0.043 + 0.065 + 0.02 ÷ 411.30%
Expected loss0.03 × 0.351.05%
Net return0.113 − 0.0105 − 0.019.25%
Return on equity with leverage0.0925 + 1 × (0.0925 − 0.065)12%
Net return if defaults double0.113 − 2 × 0.0105 − 0.018.20%
Levered return if defaults double0.082 + 1 × (0.082 − 0.065)9.90%
The answer

The all-in yield is 11.30%. Expected credit loss is 1.05% a year, so the net return is 9.25%. With the fund borrowing 1 for each 1 of equity, the return on equity is 12%. If defaults double, the unlevered net return becomes 8.20% and the levered 9.90%.
