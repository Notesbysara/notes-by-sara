Warrant Value with Dilution

IntermediateDerivativesAlso known as: equity warrant, dilution adjusted option, company issued option
← VIX-Style Variance from Option PricesWeighted Average Cost of Capital (WACC) →

Finds: A warrant's value after dilution.

When to use it: Use it to value a warrant, which is a call option issued by the company itself. When it is exercised the company creates new shares, so the stock price is diluted and the warrant is worth less than an ordinary call. This is a simple approximation. It uses an option value computed first, for instance with Black-Scholes.

FormulaExampleCalculator

The formula

W\displaystyle W=NN+M C\displaystyle =\frac{N}{N+M}\,C

In words: Warrant value = Number of shares outstanding / (Shares outstanding + New shares created if all warrants are exercised) x Value of an ordinary call with the same terms

What each symbol means

WValue of one warrantmoney
CValue of an ordinary call option with the same strike and expirymoney
NExisting shares outstandingnumber
MNew shares issued if all warrants are exercisednumber

Worked example

An ordinary call with the warrant's terms is worth 6.20. The company has 10 million shares and the warrants, if all exercised, would create 1 million new shares. What is a warrant worth?

Dilution factor10 ÷ (10 + 1)0.9091
Warrant value0.909091 × 6.25.64
Reduction1 − 0.9090919.1%
The answer

The dilution factor is 0.9091, so each warrant is worth 5.64, about 9.1% less than the ordinary call.
