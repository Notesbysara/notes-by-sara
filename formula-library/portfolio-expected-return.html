Expected Return of a Portfolio

Beginner

Also known as: weighted average return, portfolio return, asset allocation return, core satellite return

Expected return of a mix of assets. Use it to find the expected return of a mix of assets. It also works for a core-satellite portfolio, where a large core holding is combined with smaller satellite holdings.

The formula

E(Rp)=∑i=1nwi E(Ri)E(R_{p})=\sum_{i=1}^{n}w_{i}\,E(R_{i})

Portfolio expected return = w1 x E(R1) + w2 x E(R2) + ... + wn x E(Rn)

What each symbol means

SymbolMeaningUnit
E(R_p)Expected return of the portfolioper year
w_iWeight of asset i, its share of the portfolio value, with all weights adding to 1percent
E(R_i)Expected return of asset iper year

Worked example

A portfolio is 60% in shares expected to return 10% and 40% in bonds expected to return 6%. What is its expected return?

  1. Contribution of each asset = weight x return= 6.00%, 2.40%
  2. Portfolio return = sum of the contributions= 8.40%

The portfolio's expected return is 8.40%.
