Emerging Market Return: Local, Unhedged and Hedged

IntermediateInternational FinanceAlso known as: emerging markets investing, currency return, hedging cost, local currency return
← Emergency Fund Target and Monthly SavingEmployer Match and Vesting →

Finds: what a local return is worth in dollars, hedged and unhedged.

When to use it: Use it to split an emerging market return into the asset and the currency. High local returns are often offset by currency depreciation, especially where inflation is high. Hedging removes the currency move but costs the interest differential, which is large when local rates are high, so the hedged return is lower when the currency would otherwise have held. Choose by comparing the hedging cost with the depreciation you fear.

The formula

RUSD\displaystyle R_{USD}=(1+Rlocal)(1+Δs)−1\displaystyle =(1+R_{local})(1+\Delta s)-1Rhedged\displaystyle R_{hedged}=(1+Rlocal)1+rd1+rf−1\displaystyle =(1+R_{local})\frac{1+r_{d}}{1+r_{f}}-1

In words: Dollar return unhedged = (1 + local return) x (1 + change in the local currency against the dollar) − 1; Dollar return hedged with a forward = (1 + local return) x (1 + dollar interest rate) / (1 + local interest rate) − 1. Hedging cost is roughly the local rate minus the dollar rate

What each symbol means

R_localReturn on the asset in local currencypercent
Delta sChange in the value of the local currency against the dollarpercent
r_d, r_fDollar and local short-term interest ratesper year

Worked example

A local bond market returns 12% in local currency. The local currency falls 8% against the dollar. Dollar rates are 4% and local rates 9%.

Unhedged USD return(1 + 0.12) × (1+−0.08) − 13.04%
Hedged USD return(1 + 0.12) × (1 + 0.04) ÷ (1 + 0.09) − 16.86%
Approximate hedging cost0.09 − 0.045%

Hedged minus unhedged0.0686239 − 0.03043.82%
The answer

Unhedged, the dollar return is 3.04%, well below the local 12% because of the currency fall. Hedged, the return is 6.86%, since the hedge costs about 5% a year. The hedge-better flag is 1 (1 = hedged was better, 0 = unhedged was better).
