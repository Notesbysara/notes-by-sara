Binomial Option Pricing (Two Steps)

Intermediate

Also known as: Cox Ross Rubinstein, CRR, binomial tree, risk neutral probability

Option values from a binomial tree. Use it to price an option by building a tree of possible stock prices, finding the payoff at the end and discounting back at the risk-free rate using risk-neutral probabilities. More steps give prices closer to Black-Scholes. This is a European option. For an American option you would also check early exercise at each node.

The formula

u=eσΔt, d=1u, q=erΔt−du−d, V=e−rΔt[qVu+(1−q)Vd]u=e^{\sigma\sqrt{\Delta t}},\ d=\frac{1}{u},\ q=\frac{e^{r\Delta t}-d}{u-d},\ V=e^{-r\Delta t}\left[qV_{u}+(1-q)V_{d}\right]

u = e^(sigma x sqrt(dt)); d = 1/u; risk-neutral probability q = (e^(r x dt) - d) / (u - d); Option value = e^(-r x dt) x [q x Value if up + (1 - q) x Value if down], worked back from expiry

What each symbol means

SymbolMeaningUnit
u, dUp and down factors for the stock price in one stepnumber
qRisk-neutral probability of an up move. It is not the real-world probabilitypercent
sigmaVolatility of the stockper year
dtLength of one step, yearsyears
rRisk-free rate (continuous)per year

Worked example

A stock is at 100 with a volatility of 20%. The risk-free rate is 5%. Price a 1-year European call and put with a strike of 100 using two 6-month steps.

  1. Length of a step = T / 21 / 2= 0.5000
  2. Up factor = e^(sigma x sqrt(dt))exp(0.2 x sqrt(0.5))= 1.1519
  3. Down factor = 1 / u1 / 1.15191= 0.8681
  4. Risk-neutral probability of up = (e^(r dt) - d) / (u - d)(exp(0.05 x 0.5)-0.868123) / (1.15191-0.868123)= 55.39%
  5. Stock price after two ups100 x 1.15191 x 1.15191= 132.69
  6. Stock price after one up and one down100 x 1.15191 x 0.868123= 100.00
  7. Stock price after two downs100 x 0.868123 x 0.868123= 75.36
  8. Call value = e^(-2 r dt) x [q^2 Cuu + 2 q (1 - q) Cud + (1 - q)^2 Cdd]exp(-2 x 0.05 x 0.5) x (0.553908^2 x max(132.69-100, 0)+2 x 0.553908 x (1-0.553908) x max(100-100, 0)+(1-0.553908)^2 x max(75.3638-100, 0))= 9.54
  9. Put value, same method with put payoffsexp(-2 x 0.05 x 0.5) x (0.553908^2 x max(100-132.69, 0)+2 x 0.553908 x (1-0.553908) x max(100-100, 0)+(1-0.553908)^2 x max(100-75.3638, 0))= 4.66

Each step multiplies the price by 1.1519 or 0.8681, and the risk-neutral probability of an up move is 55.39%. The call is worth 9.54 and the put 4.66. Black-Scholes gives about 10.45 and 5.57 for the same inputs, so two steps are already close.
