Black-Litterman: Blending a View with Equilibrium (One Asset)

IntermediateInvestments & Portfolio TheoryAlso known as: Black Litterman, posterior return, investor views, bayesian portfolio
← Black-76: Caplet or Swaption PriceBlack-Scholes PDE Check →

Finds: A return that blends the market and an opinion.

When to use it: Use it to combine the return implied by the market with your own opinion, weighting each by how confident it is. The full model uses matrices for many assets. This is the one-asset case, which shows the idea.

FormulaExampleCalculator

The formula

E(R)\displaystyle E(R)=Π/(τσ2)+Q/ω1/(τσ2)+1/ω\displaystyle =\frac{\Pi/(\tau\sigma^{2})+Q/\omega}{1/(\tau\sigma^{2})+1/\omega}

In words: Blended return = (Equilibrium / (tau x s^2) + View / w) / (1 / (tau x s^2) + 1 / w)

What each symbol means

PiEquilibrium (market-implied) expected return of the assetper year
QThe investor's own view of the expected returnper year
tauScaling number for the uncertainty in the equilibrium return, often about 0.05number
sigmaStandard deviation of the assetper year
omegaUncertainty in the view, the square of its standard deviationnumber

Worked example

The market-implied return on an asset is 6% and its standard deviation is 18%. You believe the return will be 9%, with a standard deviation of 3% in that belief. Using tau = 0.05, what blended return results?

Precision of the equilibrium1 ÷ (0.05 × 0.18^2)617.3
Precision of the view1 ÷ 0.03^21,111.1
Blended return(0.06 × 617.284 + 0.09 × 1,111.11) ÷ (617.284 + 1,111.11)7.93%
Weight on your view1,111.11 ÷ (617.284 + 1,111.11)64.29%
The answer

The blended return is 7.93%. The view gets a weight of 64.29%, because it is held more confidently than the equilibrium estimate.
