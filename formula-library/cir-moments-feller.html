Cox-Ingersoll-Ross Moments and Feller Condition

Intermediate

Also known as: CIR model, square root process, Feller condition, non-negative interest rates

Where a square-root rate is expected to be and whether it stays positive. Use it for a mean-reverting rate that cannot go negative. Shocks shrink as the rate nears zero, which keeps it positive when the Feller condition holds. If the condition fails, the rate can touch zero (it still never goes below). The same process is used for variance in the Heston model.

The formula

E[rt]=θ+(r0−θ)e−κt,2κθ≥σ2E[r_{t}]=\theta+(r_{0}-\theta)e^{-\kappa t},\quad 2\kappa\theta\ge\sigma^{2}

Expected rate = theta + (r0 - theta) x e^(-kappa t); Variance = r0 x sigma^2 / kappa x (e^(-kappa t) - e^(-2 kappa t)) + theta x sigma^2 / (2 kappa) x (1 - e^(-kappa t))^2; the rate stays above zero if 2 x kappa x theta >= sigma^2

What each symbol means

SymbolMeaningUnit
r_0Current rateper year
thetaLong-run meanper year
kappaSpeed of reversionper year
sigmaVolatility parameter. Shocks scale with sqrt(r), so volatility falls as the rate fallsnumber

Worked example

The rate is 3%, the long-run mean is 5%, the speed is 0.8 and sigma is 0.10. Find the mean and standard deviation of the rate in 2 years and test the Feller condition.

  1. Expected rate = theta + (r0 - theta) e^(-kappa t)0.05+(0.03-0.05) x exp(-0.8 x 2)= 4.596%
  2. Variance0.03 x 0.1^2 / 0.8 x (exp(-0.8 x 2)-exp(-2 x 0.8 x 2))+0.05 x 0.1^2 / (2 x 0.8) x (1-exp(-0.8 x 2))^2= 0.00025948
  3. Standard deviationsqrt(var)= 1.611%
  4. 2 x kappa x theta2 x 0.8 x 0.05= 0.0800
  5. sigma squared0.1^2= 0.0100
  6. Feller condition holds? (1 = yes, 0 = no)1 if 0.08>=0.01 else 0= 1

In 2 years the expected rate is 4.596% with a standard deviation of 1.611%. The Feller test compares 2 kappa theta = 0.0800 with sigma squared = 0.0100. The condition holds, so the rate stays positive.
