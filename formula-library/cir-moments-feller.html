Cox-Ingersoll-Ross Moments and Feller Condition

IntermediateQuantitative FinanceAlso known as: CIR model, square root process, Feller condition, non-negative interest rates
← Covered Interest Parity and ArbitrageCredit Card Payoff Time and Interest →

Finds: where a square-root rate is expected to be and whether it stays positive.

When to use it: Use it for a mean-reverting rate that cannot go negative. Shocks shrink as the rate nears zero, which keeps it positive when the Feller condition holds. If the condition fails, the rate can touch zero (it still never goes below). The same process is used for variance in the Heston model.

The formula

E[rt]\displaystyle E[r_{t}]=θ+(r0−θ)e−κt\displaystyle =\theta+(r_{0}-\theta)e^{-\kappa t}2κθ≥σ2\displaystyle 2\kappa\theta\ge\sigma^{2}

In words: Expected rate = theta + (r0 − theta) x e^(-kappa t); Variance = r0 x sigma^2 / kappa x (e^(-kappa t) − e^(−2 kappa t)) + theta x sigma^2 / (2 kappa) x (1 − e^(-kappa t))^2; the rate stays above zero if 2 x kappa x theta >= sigma^2

Worked example

The rate is 3%, the long-run mean is 5%, the speed is 0.8 and sigma is 0.10. Find the mean and standard deviation of the rate in 2 years and test the Feller condition.

The answer

In 2 years the expected rate is 4.596% with a standard deviation of 1.611%. The Feller test compares 2 kappa theta = 0.0800 with sigma squared = 0.0100. The condition holds, so the rate stays positive.
