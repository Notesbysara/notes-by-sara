Early-Payment Discount Return (Supply Chain Finance)

Intermediate

Also known as: dynamic discounting, supply chain finance, annualized discount return

Annual return on paying a supplier early. Use it to compare an early-payment discount with the return you would earn elsewhere. A buyer with spare cash earns this return by paying a supplier early, and a supplier should compare it with the cost of its other funding.

The formula

Annualized return=d1−d×365days early\text{Annualized return}=\frac{d}{1-d}\times\frac{365}{\text{days early}}

Annualized return = d / (1 - d) x 365 / Days paid early

What each symbol means

SymbolMeaningUnit
dDiscount given for paying early, as a decimaldecimal
Days earlyHow many days sooner the invoice is paiddays

Worked example

A buyer pays an invoice 20 days early in return for a 1% discount. What annualized return does that earn?

  1. Return for the period = d / (1 - d)0.01 / (1-0.01)= 1.01%
  2. Simple annualized = return x 365 / days0.010101 x 365 / 20= 18.43%
  3. Compounded = (1 + return)^(365 / days) - 1(1+0.010101)^(365 / 20)-1= 20.13%

The return for the 20 days is 1.01%, which is about 18.43% a year (simple), or 20.13% with compounding.
