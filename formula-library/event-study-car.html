Event Study: Abnormal and Cumulative Abnormal Return

Intermediate

Also known as: abnormal return, CAR, market model event study, announcement effect

How much an event moved a stock. Use it to measure how much a news event, such as an earnings release or a merger announcement, moved a stock beyond what the market did that day. Under efficient markets the effect shows up at once and does not drift afterward.

The formula

ARt=Rt−(α+βRm,t),CAR=∑ARt,t=CARσεNAR_{t}=R_{t}-(\alpha+\beta R_{m,t}),\quad CAR=\sum AR_{t},\quad t=\frac{CAR}{\sigma_{\varepsilon}\sqrt{N}}

Abnormal return = actual return - (alpha + beta x market return); CAR = sum of the abnormal returns; t = CAR / (s x sqrt(N))

What each symbol means

Worked example

Over a 5-day window around an announcement a stock returned 0.5%, 3.2%, 1.1%, -0.4% and 0.8%, while the market returned 0.2%, 0.5%, 0.3%, -0.2% and 0.1%. Before the event the stock had an alpha of 0.02% a day and a beta of 1.1, and its abnormal returns had a daily standard deviation of 1.2%. Was the reaction significant?

  1. Expected return each day = alpha + beta x market return= 0.0024, 0.0057, 0.0035, -0.0020, 0.0013
  2. Abnormal return each day = actual - expected= 0.0026, 0.0263, 0.0075, -0.0020, 0.0067
  3. CAR = sum of the abnormal returns= 4.11%
  4. t = CAR / (se x square root of N)= 1.53

The cumulative abnormal return is 4.11%. The t-statistic is 1.53. Beyond about 2 is usually called significant, so this reaction looks real.
