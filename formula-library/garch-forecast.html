GARCH(1,1) Variance Forecast

IntermediateQuantitative FinanceAlso known as: GARCH volatility models, conditional variance, volatility clustering, long-run variance
← FX Forward Hedge and Covered Interest ParityGDP: Expenditure Approach, Real GDP and Deflator →

Finds: tomorrow's volatility and the path back to normal.

When to use it: Use it to forecast volatility that clusters: big moves are followed by big moves. A shock raises tomorrow's variance, and the effect decays at the rate alpha + beta toward the long-run level. Alpha + beta must be below 1 for a long-run level to exist; values near 1 mean shocks fade slowly.

The formula

σt+12\displaystyle \sigma_{t+1}^{2}=ω+αrt2+βσt2\displaystyle =\omega+\alpha r_{t}^{2}+\beta\sigma_{t}^{2}σˉ2\displaystyle \bar{\sigma}^{2}=ω1−α−β\displaystyle =\frac{\omega}{1-\alpha-\beta}

In words: Next-period variance = omega + alpha x (last return)^2 + beta x (last variance); Long-run variance = omega / (1 − alpha − beta); k periods ahead: long-run + (alpha + beta)^k x (next variance − long-run)

What each symbol means

omegaConstant term that sets the long-run variancenumber
alphaWeight on the last squared return (reaction to news)number
betaWeight on the last variance (persistence)number
r_tLast returnpercent
sigma_t^2Last variancenumber

Worked example

A GARCH(1,1) has omega = 0.000002, alpha = 0.08 and beta = 0.90. The last daily return was −2% and the last daily volatility was 1.5%. Forecast tomorrow and 10 days ahead.

The answer

Tomorrow's variance is 0.00023650, a daily volatility of 1.538% or 24.41% annualized. The long-run volatility is 1.000% per day and the persistence is 0.980. Ten days ahead the volatility forecast is 1.462%, drifting back toward the long-run level.
