GARCH(1,1) Variance Forecast

Intermediate

Also known as: GARCH volatility models, conditional variance, volatility clustering, long-run variance

Tomorrow's volatility and the path back to normal. Use it to forecast volatility that clusters: big moves are followed by big moves. A shock raises tomorrow's variance, and the effect decays at the rate alpha + beta toward the long-run level. Alpha + beta must be below 1 for a long-run level to exist; values near 1 mean shocks fade slowly.

The formula

σt+12=ω+αrt2+βσt2,σˉ2=ω1−α−β\sigma_{t+1}^{2}=\omega+\alpha r_{t}^{2}+\beta\sigma_{t}^{2},\quad \bar{\sigma}^{2}=\frac{\omega}{1-\alpha-\beta}

Next-period variance = omega + alpha x (last return)^2 + beta x (last variance); Long-run variance = omega / (1 - alpha - beta); k periods ahead: long-run + (alpha + beta)^k x (next variance - long-run)

Worked example

A GARCH(1,1) has omega = 0.000002, alpha = 0.08 and beta = 0.90. The last daily return was -2% and the last daily volatility was 1.5%. Forecast tomorrow and 10 days ahead.

  1. Next variance = omega + alpha r^2 + beta s^22e-06+0.08 x -0.02^2+0.9 x 0.015^2= 0.00023650
  2. Next daily volatilitysqrt(0.0002365)= 1.538%
  3. Annualized (x sqrt 252)0.0153786 x sqrt(252)= 24.41%
  4. Long-run variance = omega / (1 - alpha - beta)2e-06 / (1-0.08-0.9)= 0.00010000
  5. Long-run daily volatilitysqrt(0.0001)= 1.000%
  6. Persistence = alpha + beta0.08+0.9= 0.980
  7. Volatility k days aheadsqrt(0.0001+(0.08+0.9)^(10-1) x (0.0002365-0.0001))= 1.462%

Tomorrow's variance is 0.00023650, a daily volatility of 1.538% or 24.41% annualized. The long-run volatility is 1.000% per day and the persistence is 0.980. Ten days ahead the volatility forecast is 1.462%, drifting back toward the long-run level.
