Net Operating Income and Cap-Rate Valuation

Beginner

Also known as: NOI, capitalization rate, direct capitalization, property value from income

Property value from its income. Use it for a quick market value of an income-producing building. Dividing a steady year of income by a yield gives the price, the property-world version of a perpetuity. Cap rates move with interest rates and risk, so a small change in the rate moves value a lot. It ignores growth, so it fits stable properties best.

The formula

NOI=GPI(1−v)−OpEx,V=NOIc,c=NOIVNOI=GPI(1-v)-OpEx,\quad V=\frac{NOI}{c},\quad c=\frac{NOI}{V}

Net operating income = potential rent x (1 - vacancy) - operating expenses (before debt service, tax and depreciation); Value = NOI / cap rate; Cap rate = NOI / value; Debt service coverage = NOI / annual loan payment

What each symbol means

SymbolMeaningUnit
GPIGross potential income if fully letmoney
vVacancy and collection losspercent
OpExProperty tax, insurance, repairs, managementmoney
cCapitalization rate: income yield the market demands for this type of propertypercent

Worked example

A building could collect 500,000 in rent when full. Vacancy is 6% and operating expenses are 180,000. Comparable buildings sell at a 6.5% cap rate. A 60% loan at 5.5% interest-only is offered.

  1. NOI = rent x (1 - vacancy) - expenses500000 x (1-0.06)-180000= 290,000.00
  2. Value = NOI / cap rate290000 / 0.065= 4,461,538.46
  3. Value if the cap rate rises by 1 percentage point290000 / (0.065+0.01)= 3,866,666.67
  4. Fall in value3,866,667 / 4,461,538-1= -13.3%
  5. Loan = LTV x value0.6 x 4,461,538= 2,676,923.08
  6. Annual interest2,676,923 x 0.055= 147,230.77
  7. Debt service coverage = NOI / interest290000 / 147231= 1.97

NOI is 290,000.00. At a 6.5% cap rate the value is 4,461,538.46. A rise of one percentage point in the cap rate cuts the value to 3,866,666.67, a fall of -13.3%. The loan is 2,676,923.08 and interest costs 147,230.77, so the debt service coverage is 1.97.
