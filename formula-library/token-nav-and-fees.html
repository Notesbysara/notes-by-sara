Tokenized Asset: Value per Token and Cost of Access

Intermediate

Also known as: tokenization of real-world assets, fractional ownership, NAV per token, token premium, RWA tokens

What a token is worth and what trading it costs. Use it to check what a token is really worth. A token represents a legal claim to an asset; its price can differ from the value of the asset if few people trade it. Fees, the law that gives the claim force and the chance to redeem determine whether the token tracks the asset. Fractions lower the minimum ticket but do not by themselves create liquidity.

The formula

NAVtok=V(1−f T)N,P=NAVtok(1+δ)NAV_{tok}=\frac{V(1-f\,T)}{N},\quad P=NAV_{tok}(1+\delta)

Value per token = (asset value - annual fees x years) / tokens issued; Premium or discount = market price / value per token - 1; Cost to buy and sell = 2 x trading fee + bid-ask spread; Minimum investment = value per token

What each symbol means

SymbolMeaningUnit
VValue of the underlying asset (a building, a bond, a fund)money
NTokens issuedcount
f, TYearly structure and custody fee and years heldpercent, years
deltaPremium (or discount) of the token price to its underlying valuepercent

Worked example

A 50m property is split into 5m tokens. Annual structure and custody fees are 0.45%. The token trades at a 4% discount, and trading costs 0.35% each way.

  1. Value per token50,000,000 x (1-0.0045 x 1) / 5,000,000= 9.96
  2. Market price = value x (1 + premium)9.955 x (1+-0.04)= 9.56
  3. Round-trip trading cost2 x 0.0035= 0.70%
  4. Gain if price returns to value (before fees)9.955 / 9.5568-1= 4.17%

Each token is worth 9.96 after one year of fees. At a 4% discount the price is 9.56. A round trip costs 0.70% in trading fees; buying at the discount and selling at the value per token would earn 4.17% before fees.
