Impermanent Loss for Liquidity Providers

Intermediate

Also known as: LP loss, DeFi liquidity providing, holding vs providing liquidity, price divergence loss

Whether fees pay for the loss from price moves. Use it to see the cost to a liquidity provider when prices move. The pool sells the token that rises and buys the one that falls, so the provider ends up with less value than a holder. The loss is called impermanent because it disappears if the price returns, but it is real if the provider withdraws first.

The formula

IL=2r1+r−1,r=P1P0IL=\frac{2\sqrt{r}}{1+r}-1,\quad r=\frac{P_{1}}{P_{0}}

If the price of token A relative to token B changes by a factor r, a liquidity provider's pool share is worth 2 x sqrt(r) / (1 + r) of what the same tokens would be worth if simply held, so Impermanent loss = 2 x sqrt(r) / (1 + r) - 1 (zero when r = 1, and the same for r and 1/r); Fees earned must exceed this loss for the pool to beat holding

What each symbol means

SymbolMeaningUnit
rRatio of the new price to the starting pricenumber
ILValue of the pool position compared with holding, minus 1percent

Worked example

The price of token A doubles against token B. The pool earned 3% in fees over the same period.

  1. Impermanent loss2 x sqrt(2) / (1+2)-1= -5.72%
  2. Pool value relative to holding1+-0.057191= 94.28%
  3. Result vs holding after fees-0.057191+0.03= -2.72%
  4. Loss if the price falls to 1 / r2 x sqrt(1 / 2) / (1+1 / 2)-1= -5.72%

The impermanent loss is -5.72%. The position is worth 94.28% of a holder's value before fees. With fees of 3%, the result compared with holding is -2.72%. A fall to half the price gives the same loss, -5.72%.
