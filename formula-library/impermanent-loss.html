Impermanent Loss for Liquidity Providers

IntermediateFintech & Digital FinanceAlso known as: LP loss, DeFi liquidity providing, holding vs providing liquidity, price divergence loss
← Impact Investing: Social Return on InvestmentImplementation Shortfall and Market Impact →

Finds: whether fees pay for the loss from price moves.

When to use it: Use it to see the cost to a liquidity provider when prices move. The pool sells the token that rises and buys the one that falls, so the provider ends up with less value than a holder. The loss is called impermanent because it disappears if the price returns, but it is real if the provider withdraws first.

FormulaExampleCalculator

The formula

IL\displaystyle IL=2r1+r−1\displaystyle =\frac{2\sqrt{r}}{1+r}-1r\displaystyle r=P1P0\displaystyle =\frac{P_{1}}{P_{0}}

In words: If the price of token A relative to token B changes by a factor r, a liquidity provider's pool share is worth 2 x sqrt(r) / (1 + r) of what the same tokens would be worth if simply held, so Impermanent loss = 2 x sqrt(r) / (1 + r) − 1 (zero when r = 1, and the same for r and 1/r); Fees earned must exceed this loss for the pool to beat holding

What each symbol means

rRatio of the new price to the starting pricenumber
ILValue of the pool position compared with holding, minus 1percent

Worked example

The price of token A doubles against token B. The pool earned 3% in fees over the same period.

Impermanent loss2 × sqrt(2) ÷ (1 + 2) − 1−5.72%
Pool value relative to holding1+−0.05719194.28%
Result vs holding after fees−0.057191 + 0.03−2.72%
Loss if the price falls to 1 / r2 × sqrt(1 ÷ 2) ÷ (1 + 1 ÷ 2) − 1−5.72%
The answer

The impermanent loss is −5.72%. The position is worth 94.28% of a holder's value before fees. With fees of 3%, the result compared with holding is −2.72%. A fall to half the price gives the same loss, −5.72%.
