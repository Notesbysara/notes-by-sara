Expected Value of Perfect Information

Intermediate

Also known as: value of information, decision tree, expected monetary value, EMV, how much to pay for research

The most a forecast or study could be worth. Use it to cap what research, data or advice is worth paying for. Even a perfect forecast cannot be worth more than EVPI, so if a study costs more than this, skip it. Real information is imperfect, so its true value is lower. It depends entirely on your probabilities and payoffs, so test it with other numbers.

The formula

EVPI=E[max⁡aPayoff(a,s)]−max⁡aE[Payoff(a,s)]EVPI=E\left[\max_{a}\text{Payoff}(a,s)\right]-\max_{a}E\left[\text{Payoff}(a,s)\right]

Expected value of perfect information = (expected payoff if you could pick the best action after seeing the state) - (best expected payoff when you must choose before seeing it)

What each symbol means

SymbolMeaningUnit
aAction or choicelabel
sState of the world (boom, normal, bust)label
Payoff(a, s)Payoff of action a if state s occursmoney
p(s)Probability of each statepercent

Worked example

Three projects pay (in thousands) 40, 10 and -30 in a boom, normal and bust year (project A); 15, 12 and 5 (project B); and 0, 0 and 0 (do nothing, project C). The state probabilities are 30%, 50% and 20%.

  1. Expected payoff, project A= 11.00
  2. Expected payoff, project B= 11.50
  3. Expected payoff, project C= 0.00
  4. Best expected payoff without informationmax(11, 11.5, 0)= 11.50
  5. Expected payoff with perfect information = sum of p x best payoff in each state[0.3, 0.5, 0.2][0] x max([40, 10, -30, 15, 12, 5, 0, 0, 0][0], [40, 10, -30, 15, 12, 5, 0, 0, 0][3], [40, 10, -30, 15, 12, 5, 0, 0, 0][6])+[0.3, 0.5, 0.2][1] x max([40, 10, -30, 15, 12, 5, 0, 0, 0][1], [40, 10, -30, 15, 12, 5, 0, 0, 0][4], [40, 10, -30, 15, 12, 5, 0, 0, 0][7])+[0.3, 0.5, 0.2][2] x max([40, 10, -30, 15, 12, 5, 0, 0, 0][2], [40, 10, -30, 15, 12, 5, 0, 0, 0][5], [40, 10, -30, 15, 12, 5, 0, 0, 0][8])= 19.00
  6. EVPI = with information - without19-11.5= 7.50

The expected payoffs are 11.00 for A, 11.50 for B and 0.00 for C, so the best choice without information is worth 11.50. With perfect knowledge of the state you would pick the best project each year, worth 19.00 on average. The value of perfect information is therefore 7.50: do not pay more than this for a forecast.
