Expected Value

Beginner

Also known as: expected return, probability weighted average, E(X)

Probability-weighted average outcome. Use it to find the average outcome when several results are possible, each with its own probability, such as the expected return across economic scenarios.

The formula

E(X)=∑i=1npi xiE(X) = \sum_{i=1}^{n} p_{i}\,x_{i}

E(X) = p1 x x1 + p2 x x2 + ... + pn x xn

What each symbol means

SymbolMeaningUnit
E(X)Expected value, the probability-weighted average outcomesame as x
p_iProbability of outcome i, with all probabilities adding to 1number
x_iValue of outcome isame as x

Worked example

A stock could return 20% in a boom (probability 0.3), 8% in a normal year (0.5) or -10% in a recession (0.2). What is the expected return?

  1. Probability x outcome for each scenario= 6.00%, 4.00%, -2.00%
  2. Expected value = sum of the weighted outcomes= 8.00%

The expected return is 8.00%.
