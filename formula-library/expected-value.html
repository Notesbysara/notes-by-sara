Expected Value

BeginnerFinance FoundationsAlso known as: expected return, probability weighted average, E(X)
← Expected Shortfall (CVaR)Expected Value of Perfect Information →

Finds: probability-weighted average outcome.

When to use it: Use it to find the average outcome when several results are possible, each with its own probability, such as the expected return across economic scenarios.

FormulaExampleCalculator

The formula

E(X)\displaystyle E(X)=∑i=1npi xi\displaystyle = \sum_{i=1}^{n} p_{i}\,x_{i}

In words: E(X) = p1 x x1 + p2 x x2 + ... + pn x xn

What each symbol means

E(X)Expected value, the probability-weighted average outcomesame as x
p_iProbability of outcome i, with all probabilities adding to 1number
x_iValue of outcome isame as x

Worked example

A stock could return 20% in a boom (probability 0.3), 8% in a normal year (0.5) or −10% in a recession (0.2). What is the expected return?

Probability x outcome for each scenario6%, 4%, −2%
Expected value8%
The answer

The expected return is 8%.
