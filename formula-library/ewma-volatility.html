EWMA Volatility (RiskMetrics)

IntermediateQuantitative FinanceAlso known as: exponentially weighted moving average, RiskMetrics, decay factor, GARCH volatility models
← Event Study: Abnormal and Cumulative Abnormal ReturnEx-Dividend Price Drop →

Finds: A volatility estimate that favors recent returns.

When to use it: Use it for a quick volatility estimate that reacts to recent returns more than old ones. It is GARCH with omega = 0 and alpha + beta = 1, so it has no long-run level and its forecast is flat. It needs only one parameter, which is why risk systems used it as a default.

FormulaExampleCalculator

The formula

σt2\displaystyle \sigma_{t}^{2}=λ σt−12+(1−λ) rt−12\displaystyle =\lambda\,\sigma_{t-1}^{2}+(1-\lambda)\,r_{t-1}^{2}

In words: Variance today = lambda x yesterday's variance + (1 − lambda) x yesterday's return squared. RiskMetrics uses lambda = 0.94 for daily data

What each symbol means

lambdaDecay factor. Higher values mean a slower-moving estimatenumber
rDaily returnpercent
sigma^2Variance estimatenumber

Worked example

The last ten daily returns, oldest first, are 0.4%, −1.2%, 0.8%, −2.5%, 1.1%, −0.3%, 0.6%, −1.8%, 2.2% and −0.9%. Use lambda = 0.94, starting from the first return squared.

EWMA variance (recursion, seeded with the first squared return)0.00009967
Daily volatilitysqrt(var)0.998%
Annualized (x sqrt 252)0.00998366 × sqrt(252)15.85%
Equal-weight daily volatility (root mean square)1.380%
The answer

The current daily variance is 0.00009967, a daily volatility of 0.998% or 15.85% annualized. A plain average of the ten returns would give 1.380%, so the EWMA is weighting recent days differently.
