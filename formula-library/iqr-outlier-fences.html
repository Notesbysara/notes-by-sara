IQR Outlier Fences

Beginner

Also known as: data and coding workflow, data cleaning, Tukey fences, detect outliers, interquartile range

Values that sit far outside the bulk of the data. Use it as a first pass in cleaning data, to find values that look like errors or extreme events, such as a price typed with an extra digit. Quartiles ignore extreme values, so one bad point cannot hide itself the way it can in a mean and standard deviation test. A flagged value is a prompt to investigate, not an instruction to delete: real crashes are outliers too.

The formula

IQR=Q3−Q1,Fences=Q1−k⋅IQR,  Q3+k⋅IQRIQR=Q_{3}-Q_{1},\quad \text{Fences}=Q_{1}-k\cdot IQR,\; Q_{3}+k\cdot IQR

IQR = third quartile - first quartile; Lower fence = Q1 - k x IQR; Upper fence = Q3 + k x IQR; values outside the fences are flagged (k = 1.5 is the usual choice)

What each symbol means

SymbolMeaningUnit
Q_1, Q_325th and 75th percentiles of the datasame as data
IQRInterquartile range: the spread of the middle half of the datasame as data
kFence multiplier. 1.5 flags mild outliers, 3 flags extreme onesnumber

Worked example

Fifteen daily values are in the calculator. Which are outliers with k = 1.5?

  1. First quartile (25th percentile)= 12.50
  2. Third quartile (75th percentile)= 15.50
  3. IQR = Q3 - Q115.5-12.5= 3.00
  4. Lower fence = Q1 - k x IQR12.5-1.5 x 3= 8.00
  5. Upper fence = Q3 + k x IQR15.5+1.5 x 3= 20.00
  6. Values outside the fences= 1
  7. Mean with all values= 19.27
  8. Mean without the flagged values= 13.86

The quartiles are 12.50 and 15.50, so the IQR is 3.00 and the fences are 8.00 and 20.00. 1 value lies outside, the 95. The mean is 19.27 with it and 13.86 without, which shows how much one point can move it.
