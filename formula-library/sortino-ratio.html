Sortino Ratio

Intermediate

Also known as: downside deviation, downside risk adjusted return, minimum acceptable return

Return per unit of downside risk. Use it like the Sharpe ratio when only losses are the real concern. It ignores upside swings, which investors do not mind, and measures return per unit of downside risk.

The formula

Sortino=Rˉ−MARDD,DD=1n∑min⁡(Ri−MAR,0)2\text{Sortino}=\frac{\bar{R}-MAR}{DD},\quad DD=\sqrt{\frac{1}{n}\sum\min(R_{i}-MAR,0)^{2}}

Sortino = (Average return - MAR) / Downside deviation, where Downside deviation = square root of the average of min(Ri - MAR, 0)^2

What each symbol means

SymbolMeaningUnit
R-barAverage returnpercent
MARMinimum acceptable return, the target the investor wants to beatpercent
DDDownside deviation, risk measured only from returns below the MARpercent
nNumber of returns, counting all of themnumber

Worked example

A fund returned 3%, -2%, 5%, 1%, -4%, 6%, 2% and -1% over eight months. The minimum acceptable return is 0.5% a month. What is its Sortino ratio?

  1. Average return= 1.25%
  2. Downside deviation= 1.90%
  3. Sortino = (average - MAR) / downside deviation(0.0125-0.005) / 0.0189572= 0.396

The average return is 1.25% and the downside deviation is 1.90%. The Sortino ratio is 0.396 per month.
