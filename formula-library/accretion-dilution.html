Accretion/Dilution Analysis (Stock Deal)

Intermediate

Also known as: EPS accretion, pro forma EPS, merger EPS impact

EPS effect of a share-funded acquisition. Use it to see whether paying for a target with shares raises (accretive) or lowers (dilutive) the buyer's earnings per share. EPS impact is not the same as value created, but the market watches it.

The formula

EPSpro forma=NIA+NITNA+Nnew,Nnew=Price paidPAEPS_{pro\ forma}=\frac{NI_{A}+NI_{T}}{N_{A}+N_{new}},\quad N_{new}=\frac{\text{Price paid}}{P_{A}}

Pro forma EPS = (Acquirer NI + Target NI) / (Acquirer shares + New shares), where New shares = Price paid / Acquirer share price

What each symbol means

Worked example

A buyer earns 800 with 400 shares (EPS 2.00). It buys a target earning 200 for 3,000, paid entirely in new shares at 40 each. Is the deal accretive?

  1. New shares = price paid / acquirer price3000 / 40= 75
  2. EPS before = acquirer NI / acquirer shares800 / 400= 2.00
  3. Pro forma EPS = (NI A + NI T) / (N A + new shares)(800+200) / (400+75)= 2.11
  4. Change in EPS2.10526 / 2-1= 5.26%

The buyer issues 75 new shares. Pro forma EPS is 2.11 against 2.00 before, so the deal is accretive, raising EPS by 5.26%.
