Terminal Value (Exit Multiple Method)

Intermediate

Also known as: exit multiple, TV multiple, terminal EBITDA multiple

Terminal value from a market multiple. Use it to set the terminal value from market multiples. Always check the growth rate it implies. A multiple that implies growth above the economy's long-run rate is too high.

The formula

TVn=EBITDAn×M,gimplied=TV⋅WACC−FCFFnTV+FCFFnTV_{n}=EBITDA_{n}\times M,\quad g_{implied}=\frac{TV\cdot WACC-FCFF_{n}}{TV+FCFF_{n}}

Terminal value = Final-year EBITDA x Exit multiple; Implied g = (TV x WACC - FCFF) / (TV + FCFF)

What each symbol means

SymbolMeaningUnit
TV_nTerminal value at the end of the forecastmoney
EBITDA_nEarnings before interest, tax, depreciation and amortization in the final yearmoney
MExit multiple, taken from comparable companiesnumber
g_impliedPerpetual growth rate that the multiple impliesper year

Worked example

Final-year EBITDA is 300 and comparable companies trade at 8 times EBITDA. Final-year FCFF is 140 and WACC is 9%. What is the terminal value and the growth it implies?

  1. TV = EBITDA x multiple300 x 8= 2,400.00
  2. Implied g = (TV x WACC - FCFF) / (TV + FCFF)(2400 x 0.09-140) / (2400+140)= 2.99%

The terminal value is 2,400.00, which implies perpetual growth of 2.99%. That is a reasonable long-run rate.
