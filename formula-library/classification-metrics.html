Classification Metrics: Precision, Recall and F1

Beginner

Also known as: confusion matrix, machine learning in finance, accuracy, false positives, default prediction

How good a yes/no model really is when the event is rare. Use it to judge a model that sorts cases into classes, such as default or no default, or fraud or genuine. When the event is rare, accuracy misleads: a model that never flags anything can be 98% accurate. Precision tells you how many flags are real, recall how many real cases were caught, and F1 balances the two.

The formula

Precision=TPTP+FP,  Recall=TPTP+FN,  F1=2 P RP+R,  Accuracy=TP+TNTP+FP+FN+TNPrecision=\frac{TP}{TP+FP},\; Recall=\frac{TP}{TP+FN},\; F_{1}=\frac{2\,P\,R}{P+R},\; Accuracy=\frac{TP+TN}{TP+FP+FN+TN}

Precision = TP / (TP + FP); Recall = TP / (TP + FN); F1 = 2 x Precision x Recall / (Precision + Recall); Accuracy = (TP + TN) / total

What each symbol means

SymbolMeaningUnit
TPTrue positives: flagged and correctcount
FPFalse positives: flagged but wrongcount
FNFalse negatives: missedcount
TNTrue negatives: not flagged and correctcount

Worked example

A default model scores 1,000 loans. It flags 60 as defaults and 45 of those do default. In total 50 loans default.

  1. Accuracy = (TP + TN) / total(45+935) / (45+15+5+935)= 98.00%
  2. Precision = TP / (TP + FP)45 / (45+15)= 75.00%
  3. Recall = TP / (TP + FN)45 / (45+5)= 90.00%
  4. F1 = 2 x precision x recall / (precision + recall)2 x 0.75 x 0.9 / (0.75+0.9)= 81.82%
  5. Accuracy of a model that never flags anything(15+935) / (45+15+5+935)= 95.00%

Accuracy is 98.00%, which looks excellent but is mostly the many good loans. Precision is 75.00% (of the flagged loans, this share defaulted) and recall is 90.00% (of the loans that defaulted, this share was caught). F1 is 81.82%. A model that flagged nothing would score 95.00% accuracy with zero recall.
