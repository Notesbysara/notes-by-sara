Bitcoin Mining: Revenue, Electricity Cost and Break-Even Price

Intermediate

Also known as: mining profitability, hash rate share, electricity cost per BTC, hashprice

The price needed to cover electricity. Use it to see the price at which a mining machine stops paying for its power. Mining is a competition: when more computing power joins, each machine wins a smaller share. Costs of the machine, hosting and pool fees are left out here, so the true break-even is higher.

The formula

BTC/day=hH B (R+F),P∗=kW×24×cBTC/dayBTC/day=\frac{h}{H}\,B\,(R+F),\quad P^{*}=\frac{kW\times 24\times c}{BTC/day}

Share of the network = miner hash rate / network hash rate; Coins won per day = share x blocks per day (144) x (block reward + average fees per block); Daily electricity cost = power in kW x 24 x price per kWh; Break-even price = daily cost / coins won per day

What each symbol means

SymbolMeaningUnit
h, HMiner's and the whole network's hash ratehashes per second
R, FBlock reward and average transaction fees per blockcoins
cElectricity pricemoney per kWh

Worked example

A machine runs at 200 TH/s and uses 3 kW. The network runs at 700 EH/s. The block reward is 3.125 coins with 0.25 coins of fees per block. Power costs 0.06 per kWh.

  1. Share of network = h / (EH/s x 1,000,000)200 / (700 x 1000000)= 0.000000286
  2. Coins won per day2.85714e-07 x 144 x (3.125+0.25)= 0.000139
  3. Coins won per year0.000138857 x 365= 0.0507
  4. Electricity cost per day3 x 24 x 0.06= 4.32
  5. Break-even price per coin (power only)4.32 / 0.000138857= 31,111.11
  6. Daily profit at a price of 60,0000.000138857 x 60000-4.32= 4.01

The machine has 0.000000286 of the network and wins 0.000139 coins a day, or about 0.0507 a year. Electricity costs 4.32 a day, so the break-even price from power alone is 31,111.11 per coin. At a price of 60,000 the daily profit before machine cost is 4.01.
