Interest on Average Debt with a Cash Sweep (Circularity Solved)

Intermediate

Also known as: circular reference, average balance interest, cash sweep, debt schedule

Closing debt and interest with no circular reference. Use it to avoid a circular reference in a model. Interest on the average balance depends on closing debt, which depends on the cash left after interest, which depends on interest. Solving the loop algebraically gives the answer in one step, with no iteration or macro, and no risk of the model breaking.

The formula

B1=B0(1+(1−t)r2)−F1−(1−t)r2,Interest=r B0+B12B_{1}=\frac{B_{0}\left(1+\tfrac{(1-t)r}{2}\right)-F}{1-\tfrac{(1-t)r}{2}},\quad \text{Interest}=r\,\frac{B_{0}+B_{1}}{2}

Closing debt B1 = [Opening debt x (1 + (1 - t) x r / 2) - Cash available F] / [1 - (1 - t) x r / 2]; Interest = Rate x (Opening + Closing) / 2

What each symbol means

Worked example

Opening debt is 600 at 6% interest. The tax rate is 25%. Cash flow before interest available for repayment, after tax on operations, is 150, all of which is swept to debt.

  1. k = (1 - t) x r / 2(1-0.25) x 0.06 / 2= 0.02250
  2. Closing debt B1 = (B0 x (1 + k) - F) / (1 - k)(600 x (1+0.0225)-150) / (1-0.0225)= 474.17
  3. Interest = r x (B0 + B1) / 20.06 x (600+474.169) / 2= 32.23
  4. Repayment = B0 - B1600-474.169= 125.83
  5. Check: F - interest x (1 - t)150-32.2251 x (1-0.25)= 125.83

Closing debt is 474.17. Interest on the average balance is 32.23, and repayment is 125.83. Check: cash available less after-tax interest is 125.83, the same as the repayment.
