Return on a Margin Purchase

Intermediate

Also known as: buying on margin, leverage return, margin loan, levered equity return

How borrowing magnifies a return. Use it to see how borrowing magnifies results. A gain is multiplied by the leverage, and so is a loss, and the interest cost is charged either way.

The formula

Requity=Q (P1−P0)−L i tE,L=Q P0−ER_{equity}=\frac{Q\,(P_{1}-P_{0})-L\,i\,t}{E},\quad L=Q\,P_{0}-E

Return on equity = (Shares x Price change - Loan x Interest rate x Years) / Your own money; Loan = Shares x Start price - Your own money

What each symbol means

SymbolMeaningUnit
EYour own money put inmoney
LAmount borrowed from the brokermoney
QShares bought, total purchase divided by the start pricenumber
P_0, P_1Price at the start and at the endmoney

Worked example

You have 10,000 and buy shares at 50 with an initial margin of 50%, so total buying is 20,000. The price rises to 60 after one year. The margin loan costs 6%. What is your return, compared with buying without a loan?

  1. Total purchase = own money / margin10000 / 0.5= 20,000.00
  2. Loan = total purchase - own money20000-10000= 10,000.00
  3. Shares = purchase / start price20000 / 50= 400.0
  4. Interest = loan x rate x years10000 x 0.06 x 1= 600.00
  5. Ending equity = shares x end price - loan - interest400 x 60-10000-600= 13,400.00
  6. Return on own money = (equity - own money) / own money(13400-10000) / 10000= 34.00%
  7. Return without a loan = p1 / p0 - 160 / 50-1= 20.00%

You bought 400.0 shares with a loan of 10,000.00. After interest of 600.00 your equity grows to 13,400.00, a return of 34.00%. Without borrowing the same price rise gives 20.00%. A fall of the same size would hurt by the same multiple.
