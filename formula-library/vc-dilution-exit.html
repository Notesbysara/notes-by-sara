Venture Capital Dilution and Required Exit Value

Intermediate

Also known as: VC economics, pre-money post-money, dilution across funding rounds, venture return multiple

How much a venture stake shrinks and the exit it needs. Use it to judge what a venture investment must return. Early stakes shrink with each round and employee option pool, so a 20% stake can end at 10% or less. Because most startups fail, the winners must return many times the fund, so the exit value needed is large. Work it backwards from the multiple you need.

The formula

Stake=IVpre+I,sexit=s0∏(1−dk),Vreq=M×Isexit\text{Stake}=\frac{I}{V_{pre}+I},\quad s_{exit}=s_{0}\prod(1-d_{k}),\quad V_{req}=\frac{M\times I}{s_{exit}}

Post-money value = pre-money value + investment; Ownership bought = investment / post-money; Each later round dilutes existing holders by (new investment / new post-money value); Stake at exit = initial stake x product of (1 - dilution) x (1 - option pool share); Exit value needed for a multiple M = M x investment / stake at exit

Worked example

A seed round invests 2m at an 8m pre-money value. Later rounds are 10m at 30m pre, then 30m at 100m pre, and an option pool takes 10%. The investor wants 10 times the 2m.

  1. Stake bought at seed = I / (pre + I)2 / (8+2)= 20.00%
  2. Series A dilution10 / (30+10)= 25.0%
  3. Series B dilution30 / (100+30)= 23.1%
  4. Stake at exit0.2 x (1-0.25) x (1-0.230769) x (1-0.1)= 10.38%
  5. Proceeds at the test exit value0.103846 x 500= 51.92
  6. Multiple of money at that exit51.9231 / 2= 25.96
  7. Exit value needed for the target multiple10 x 2 / 0.103846= 192.59

The seed round buys 20.00% of the company. After the later rounds and the option pool the stake is 10.38%. A 500m exit would pay 51.92, which is 25.96 times the 2m invested. To earn 10 times the investment the exit value must be at least 192.59.
