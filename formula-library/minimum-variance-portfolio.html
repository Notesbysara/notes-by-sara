Minimum-Variance Portfolio (Two Assets)

Intermediate

Also known as: Markowitz, mean variance optimization, efficient frontier, global minimum variance

The lowest-risk mix of two assets. Use it to find the mix of two assets with the lowest risk. It is the left-most point of the efficient frontier. A negative weight means that asset should be sold short, and this formula allows it.

The formula

w1∗=σ22−ρσ1σ2σ12+σ22−2ρσ1σ2w_{1}^{*}=\frac{\sigma_{2}^{2}-\rho\sigma_{1}\sigma_{2}}{\sigma_{1}^{2}+\sigma_{2}^{2}-2\rho\sigma_{1}\sigma_{2}}

Weight in asset 1 = (s2^2 - rho x s1 x s2) / (s1^2 + s2^2 - 2 x rho x s1 x s2), and asset 2 gets the rest

Worked example

Asset 1 has a standard deviation of 20% and expected return of 10%. Asset 2 has 12% and 6%. Their correlation is 0.3. What mix has the lowest risk?

  1. Denominator = s1^2 + s2^2 - 2 x rho x s1 x s20.2^2+0.12^2-2 x 0.3 x 0.2 x 0.12= 0.04000
  2. w1 = (s2^2 - rho x s1 x s2) / denominator(0.12^2-0.3 x 0.2 x 0.12) / 0.04= 18.00%
  3. w2 = 1 - w11-0.18= 82.00%
  4. Portfolio variance0.18^2 x 0.2^2+0.82^2 x 0.12^2+2 x 0.18 x 0.82 x 0.3 x 0.2 x 0.12= 0.01310
  5. Portfolio standard deviationsqrt(var)= 11.45%
  6. Portfolio expected return0.18 x 0.1+0.82 x 0.06= 6.72%

The lowest-risk mix is 18.00% in asset 1 and 82.00% in asset 2. Its standard deviation is 11.45%, below that of either asset, with an expected return of 6.72%.
