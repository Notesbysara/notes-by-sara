Carhart Four-Factor Model Return

Intermediate

Also known as: Carhart, momentum factor, WML, four factor model

Return implied by four factors including momentum. Use it to add momentum to the Fama-French model. Stocks that have recently risen tend to keep rising for a while, and this factor captures that.

The formula

E(R)=rf+βm(MKT)+βs(SMB)+βh(HML)+βw(WML)E(R)=r_{f}+\beta_{m}(MKT)+\beta_{s}(SMB)+\beta_{h}(HML)+\beta_{w}(WML)

Expected return = rf + b_mkt x MKT + b_smb x SMB + b_hml x HML + b_wml x WML

What each symbol means

SymbolMeaningUnit
MKT, SMB, HMLThe market, size and value factors from the Fama-French modelper year
WMLMomentum premium, past winners minus past losersper year
beta_wStock's exposure to momentum, positive for recent winnersnumber

Worked example

The risk-free rate is 3%. A stock has betas of 1.0 (market), 0.2 (size), 0.1 (value) and 0.4 (momentum). The premiums are 5.5%, 2%, 3% and 4%. What does the four-factor model predict?

  1. Beta x premium for each factor= 5.50%, 0.40%, 0.30%, 1.60%
  2. Total factor premium= 7.80%
  3. Expected return = rf + factor premium0.03+0.078= 10.80%
  4. Momentum contribution = last term= 1.60%

The four factors add 7.80%, so the expected return is 10.80%. Momentum contributes 1.60% of that.
