Carhart Four-Factor Model Return

IntermediateInvestments & Portfolio TheoryAlso known as: Carhart, momentum factor, WML, four factor model
← Carbon Markets: Abate or Buy PermitsCarry Trade Return and Break-Even →

Finds: return implied by four factors including momentum.

When to use it: Use it to add momentum to the Fama-French model. Stocks that have recently risen tend to keep rising for a while, and this factor captures that.

FormulaExampleCalculator

The formula

E(R)\displaystyle E(R)=rf+βm(MKT)+βs(SMB)+βh(HML)+βw(WML)\displaystyle =r_{f}+\beta_{m}(MKT)+\beta_{s}(SMB)+\beta_{h}(HML)+\beta_{w}(WML)

In words: Expected return = rf + b_mkt x MKT + b_smb x SMB + b_hml x HML + b_wml x WML

What each symbol means

MKT, SMB, HMLThe market, size and value factors from the Fama-French modelper year
WMLMomentum premium, past winners minus past losersper year
beta_wStock's exposure to momentum, positive for recent winnersnumber

Worked example

The risk-free rate is 3%. A stock has betas of 1.0 (market), 0.2 (size), 0.1 (value) and 0.4 (momentum). The premiums are 5.5%, 2%, 3% and 4%. What does the four-factor model predict?

Beta x premium for each factor5.50%, 0.40%, 0.30%, 1.60%
Total factor premium7.80%
Expected return0.03 + 0.07810.80%
Momentum contribution1.60%
The answer

The four factors add 7.80%, so the expected return is 10.80%. Momentum contributes 1.60% of that.
