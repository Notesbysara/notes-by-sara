Endowment Spending Rule (Yale)

Intermediate

Also known as: Yale endowment model, smoothed spending, endowment spending policy

A smoothed yearly spending amount. Use it to set a steady spending amount for an endowment. The rule blends last year's spending with a share of the fund's current value, so spending moves slowly when markets move quickly.

The formula

St=ρ St−1+(1−ρ) s MVt−1S_{t}=\rho\,S_{t-1}+(1-\rho)\,s\,MV_{t-1}

Spending this year = rho x Last year's spending + (1 - rho) x Target spending rate x Last year's market value

What each symbol means

SymbolMeaningUnit
S_tSpending this yearmoney
S_(t-1)Last year's spendingmoney
rhoSmoothing weight on last year's spending, often about 0.8number
sTarget spending rate as a share of the fund, often about 5%per year
MV_(t-1)Market value of the endowment at the start of the yearmoney

Worked example

An endowment spent 4.0 million last year and was worth 90 million at the start of this year. With a smoothing weight of 80% and a target rate of 5%, what is this year's spending?

  1. Smoothed part = rho x last year's spending0.8 x 4= 3.200
  2. Target part = (1 - rho) x s x market value(1-0.8) x 0.05 x 90= 0.900
  3. Spending = smoothed part + target part3.2+0.9= 4.100
  4. Spending as a share of the fund4.1 / 90= 4.56%
  5. For comparison, a pure rate rule = s x market value0.05 x 90= 4.500

Spending is 4.100 million, which is 4.56% of the fund. The pure 5% rule would give 4.500 million, so the smoothing rule changes spending more gently.
