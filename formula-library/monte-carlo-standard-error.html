Monte Carlo Standard Error and Confidence Interval

Intermediate

Also known as: Monte Carlo pricing, simulation error, number of paths, confidence interval for price

How accurate a simulated price is and how many paths you need. Use it to judge how accurate a simulated price is. The error shrinks with the square root of the number of paths, so halving the error needs four times as many paths. A 95% confidence interval is the estimate plus or minus 1.96 standard errors. Variance reduction tricks lower s without more paths.

The formula

V^=1N∑i=1NPVi,SE=sN,Nneeded=(starget SE)2\hat{V}=\frac{1}{N}\sum_{i=1}^{N}\text{PV}_{i},\quad SE=\frac{s}{\sqrt{N}},\quad N_{\text{needed}}=\left(\frac{s}{\text{target SE}}\right)^{2}

Price estimate = average of the discounted payoffs; Standard error = sample standard deviation / sqrt(N); Paths needed for a target error = (sample standard deviation / target error)^2

Worked example

A simulation of 20 paths gives these discounted payoffs: 0, 0, 4.2, 12.5, 0, 7.8, 0, 19.3, 2.1, 0, 0, 6.4, 0, 9.9, 3.3, 0, 0, 15.2, 1.1, 0. Find the price, its error, a 95% interval and the paths needed for an error of 0.25. (20 paths is far too few in practice; it only keeps the example short.)

  1. Number of paths N= 20
  2. Price estimate = average payoff= 4.0900
  3. Sample standard deviation of the payoffs= 5.8901
  4. Standard error = s / sqrt(N)5.89013 / sqrt(20)= 1.3171
  5. 95% interval, lower = estimate - 1.96 x SE4.09-1.96 x 1.31707= 1.5085
  6. 95% interval, upper = estimate + 1.96 x SE4.09+1.96 x 1.31707= 6.6715
  7. Paths needed = (s / target)^2, rounded up= 556

The estimate is 4.0900 with a standard error of 1.3171. The 95% interval runs from 1.5085 to 6.6715. To bring the error down to 0.25 would need about 556 paths.
