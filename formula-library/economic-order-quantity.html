Economic Order Quantity (EOQ)

Intermediate

Also known as: EOQ, inventory ordering, optimal order size

The cost-minimizing order size. Use it to choose how much stock to order at a time. Larger orders mean fewer order costs but more holding costs, and EOQ balances the two.

The formula

EOQ=2DSHEOQ=\sqrt{\frac{2DS}{H}}

EOQ = square root of (2 x Annual demand x Cost per order / Holding cost per unit)

What each symbol means

SymbolMeaningUnit
EOQOrder size that minimizes total ordering and holding costunits
DAnnual demandunits
SFixed cost of placing one ordermoney
HCost of holding one unit for a yearmoney per unit

Worked example

A shop sells 10,000 units a year. Each order costs 50 to place and holding one unit for a year costs 2. What is the economic order quantity?

  1. EOQ = sqrt(2 x D x S / H)sqrt(2 x 10000 x 50 / 2)= 707.1
  2. Orders per year = D / EOQ10000 / 707.107= 14.1
  3. Total cost = orders x S + (EOQ / 2) x H14.1421 x 50+707.107 / 2 x 2= 1,414.21

The best order size is 707.1 units, which means about 14.1 orders a year and a total annual cost of 1,414.21.
