Market Value Added (MVA)

BeginnerCorporate FinanceAlso known as: MVA, shareholder value created, goal of the firm
← Market Ratios: P/B, P/S and EV/EBITDAMarket-Cap-Weighted Index →

Finds: value created for investors.

When to use it: Use it to measure whether a firm has created or destroyed value for its investors. A positive MVA means the market values the firm above the capital invested in it.

FormulaExampleCalculator

The formula

MVA\displaystyle MVA=Market value of the firm−Capital invested\displaystyle =\text{Market value of the firm}-\text{Capital invested}

In words: MVA = (Market value of equity + Market value of debt) − Capital invested

What each symbol means

MVAMarket value added, value created beyond the capital put inmoney
Market value of equityShare price x shares outstandingmoney
Market value of debtMarket value of the firm's debtmoney
Capital investedTotal capital supplied by shareholders and lendersmoney

Worked example

A company's shares are worth 5,000 in total and its debt is worth 2,000. Investors have supplied 6,000 of capital. What is its MVA?

Market value of the firm5,000 + 2,0007,000
Capital invested6,0006,000
MVA7,000 − 6,0001,000
The answer

The firm is worth 7,000 in the market against 6,000 invested, so it has created 1,000 of value.
