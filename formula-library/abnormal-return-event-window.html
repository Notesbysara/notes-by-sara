Cumulative Abnormal Return before an Announcement

IntermediateRegulation, Ethics & ESGAlso known as: detecting insider trading, event study, market-adjusted return, abnormal return surveillance
← Crypto ETF vs Direct Holding: Fee Drag and CostCumulative Voting: Shares Needed to Elect Directors →

Finds: whether a pre-announcement price move is unusual.

When to use it: Use it to see how surveillance teams flag possible trading on secret information. A stock that rises well beyond what the market explains in the days before a takeover announcement is a warning sign, not proof. Other news, rumors or analysis can explain the move. The test compares the run-up with normal day-to-day noise.

The formula

ARt\displaystyle AR_{t}=Rt−(α+βRm,t)\displaystyle =R_{t}-(\alpha+\beta R_{m,t})CAR\displaystyle CAR=∑tARt\displaystyle =\sum_{t}AR_{t}z\displaystyle z=CARσN\displaystyle =\frac{CAR}{\sigma\sqrt{N}}

In words: Abnormal return on day t = stock return − (alpha + beta x market return); Cumulative abnormal return = sum of abnormal returns over the window before the announcement; z-score = CAR / (daily residual volatility x square root of the number of days); Large unexplained run-ups before news can prompt an investigation

What each symbol means

alpha, betaIntercept and market sensitivity estimated from normal trading daysnumber
sigmaDaily volatility of the residual (unexplained return) in normal timespercent
NNumber of days in the windowcount

The answer

The stock's cumulative return was 14.40%, of which the market explains 2.17%. The cumulative abnormal return is 12.23%. The z-score is 3.22, which is 1 (1 = above 2, worth a closer look; 0 = within normal noise).
