AI Fraud Model: Net Value of Alerts

Intermediate

Also known as: AI in banking, trading and advice, fraud detection model, false positives, alert review cost, precision and recall

What a detection model is worth in money. Use it to judge a machine-learning model by money, not accuracy alone. A model that flags many harmless transactions costs analyst time and annoys customers; one that is too cautious lets fraud through. Choose the alert threshold where the net value is highest. The same logic applies to credit models and trading signals, with their own cost of an error.

The formula

Net=TP×L−(TP+FP)×c,Precision=TPTP+FP, Recall=TPTP+FN\text{Net}=TP\times L-(TP+FP)\times c,\quad \text{Precision}=\frac{TP}{TP+FP},\ \text{Recall}=\frac{TP}{TP+FN}

Fraud stopped = true alerts x average loss per fraud; Review cost = all alerts (true + false) x cost to review one alert; Net value = fraud stopped - review cost; Missed fraud = missed cases x average loss; Precision = true alerts / all alerts; Recall = true alerts / all frauds

What each symbol means

SymbolMeaningUnit
TPAlerts that were real fraudcount
FPAlerts that were not fraud (wasted review)count
FNFrauds the model missedcount
LAverage loss per fraud casemoney
cCost to review one alertmoney

Worked example

In a month a fraud model raised 800 alerts: 420 were real fraud and 380 were not. It missed 80 frauds. The average fraud costs 1,200 and an alert costs 25 to review.

  1. Fraud stopped420 x 1200= 504,000.00
  2. Review cost(420+380) x 25= 20,000.00
  3. Net value504000-20000= 484,000.00
  4. Missed fraud80 x 1200= 96,000.00
  5. Precision420 / (420+380)= 52.5%
  6. Recall420 / (420+80)= 84.0%

The model stopped 504,000.00 of fraud and cost 20,000.00 in reviews, a net value of 484,000.00. It missed 96,000.00 of fraud. Precision is 52.5% and recall is 84.0%.
