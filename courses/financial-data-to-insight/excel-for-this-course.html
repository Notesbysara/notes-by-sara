Toolkit A · Before Topic 1

Excel for this course

You don't need to be an Excel expert for this course. You need about a dozen skills, used again and again. This toolkit teaches exactly those.

What you'll be able to do: write the formulas this course uses, from SUM and IF to SUMIFS and lookups, and summarize a table with a PivotTable. You'll also clean messy columns and build a chart in a few clicks.

Already confident? Check yourself

If you can already do all of these, you can skip this toolkit and come back to it when you need it.

  • Make a formula that still works when you copy it down a column (the $ sign)
  • Total sales for one region with SUMIFS
  • Bring a value from another table with XLOOKUP or INDEX and MATCH
  • Summarize a table by region with a PivotTable
  • Fix extra spaces and numbers stored as text

Formulas you'll use again and again​

1

Start with SUM, AVERAGE and ROUND

Every formula starts with an equals sign. =SUM(F6:F13) adds the range and gives 5,284. =AVERAGE(F6:F13) gives 660.5.

=ROUND(number, digits) rounds a result. For example, the average price of a pair of shoes is 4,420 ÷ 69 = 64.057…, and =ROUND(4420/69, 2) gives 64.06.

Tip ROUND changes the value itself. Formatting a cell to show two decimals only changes how it looks. If you add up rounded values, the total can differ slightly from the rounded total.

Helps with almost every topic.

2

Make formulas copy correctly with $

When you copy a formula down, Excel shifts its cell references. That's usually what you want, but not always.

Example To find each row's share of total sales, put the total in a cell outside the table, such as N6, and write =F6/$N$6 in G6. Copy it down. F6 becomes F7, F8 and so on, but $N$6 stays fixed. Without the $ signs, row 7 would divide by N7, which holds a different number, so every answer below the first would be wrong.

Tip Click a reference in the formula bar and press F4 to cycle through the $ options. On a Mac, press Command+T.

Helps with Topics 6 and 7, when you copy ratio and forecast formulas.

3

Make decisions with IF

=IF(test, value if true, value if false) returns one of two results.

Example With budget revenue in N7 and actual revenue in N8, =IF(N8>N7,"Favorable","Unfavorable") labels the variance. For cost rows, flip the test. A zero variance shows as Unfavorable, so check those by hand.

Helps with Topic 7.

Add up and count by condition​

SUMIFS adds the values in one range where other ranges meet the conditions you set. COUNTIFS counts the rows that meet them.

What you wantFormulaResult
Sales in the North=SUMIFS(F6:F13, C6:C13, "North")4,049
Shoe sales in the North=SUMIFS(F6:F13, C6:C13, "North", D6:D13, "Shoes")3,185
Number of rows for store S02=COUNTIFS(B6:B13, "S02")4

The order matters: in SUMIFS, the range you're adding comes first, then each condition as a pair of range and value.

Tip COUNTIFS finds duplicates. In a new column, =COUNTIFS($A$6:$A$13,A6,$B$6:$B$13,B6,$D$6:$D$13,D6) counts how many rows share this row's date, store and product. Anything above 1 is a possible duplicate, the same check Topic 3 uses, at this table's level of detail.

Helps with Topics 3 and 6, for totals by store, region or product.

Bring in values from another table​

Often the value you need sits in a different table. Suppose a store list in K5:L11 has each store and its region. To fill in a region column automatically, for example in column I:

Excel versionFormula in I6
Microsoft 365, Excel 2021 and later=XLOOKUP(B6, $K$6:$K$11, $L$6:$L$11)
Any version=INDEX($L$6:$L$11, MATCH(B6, $K$6:$K$11, 0))

Both say: find this row's store in the store list, and return the region next to it. The 0 in MATCH asks for an exact match, which is almost always what you want.

Tip If a lookup returns #N/A, the value usually isn't in the list, often because of an extra space. That's where TRIM, below, comes in.

Helps with Topics 2 and 3, for adding regions or product details to a sales file.

Summarize a table with a PivotTable​

A PivotTable summarizes a table by grouping rows and totaling values, without writing any formulas.

1

Insert it

Click inside the table, then Insert › PivotTable, and choose a new worksheet.

2

Drag the fields

Drag Region to Rows and Sales to Values. Excel shows North 4,049, South 1,235 and a grand total of 5,284. Drag Product to Columns to split each region by product.

3

Check it

Make sure the Values field says “Sum of Sales”, not “Count of Sales”. Excel counts instead of sums when a column contains any text or blank cells, such as a number stored as text.

Tip A PivotTable doesn't update by itself. After changing the data, right-click it and choose Refresh.

Helps with Topics 3 and 9.

Helps with Topic 3.

Build a chart quickly​

Select the data, including the headers, then Insert › Recommended Charts, or pick a type from the Charts group. Then:

  • Click the chart, then the Chart Elements (+) button beside it, to add or remove titles, labels and gridlines. On a Mac, use Chart Design › Add Chart Element.
  • Click the chart title and type your finding as the title.
  • Right-click any part of the chart and choose Format to change colors or axes.

Tip Topics 8 and 9 explain which chart to choose and how to keep it honest. This toolkit just gets it on the page.

Helps with Topics 8 and 9.

Try it yourself (optional)

Using the table above, write a formula for each:

1. Total bag sales in the North.

2. The number of rows for March 3.

3. Each row's average price per item, in column H, rounded to two decimals.

Show the answer

1. =SUMIFS(F6:F13, C6:C13, "North", D6:D13, "Bags") gives 864 (384 + 240 + 240).

2. =COUNTIFS(A6:A13, DATE(2025,3,3)) gives 5. DATE builds the date from year, month and day, so Excel matches it however the cell is formatted.

3. In H6, =ROUND(F6/E6, 2), then copy it down. Row 6 gives 65.00, and row 10 (S03 shoes) gives 61.75. No $ signs are needed, because each row should use its own cells.

Remember

  • Start every formula with =, and use $ to fix a reference when you copy it.
  • SUMIFS adds and COUNTIFS counts, by one or more conditions. The sum range comes first.
  • XLOOKUP, or INDEX and MATCH, bring in values from another table.
  • A PivotTable summarizes without formulas. Refresh it after the data changes.
  • Clean in a copy: TRIM, Convert to Number, Remove Duplicates and Text to Columns.
